# M1HistoryLogger（MT4インジケーター）

M1（1分足）のヒストリーデータをCSVログとして専用フォルダへ書き出すインジケーターです。

- 起動時に出力先フォルダを自動作成します（例：`C:\MT4_M1_History\USDJPY\`）
- 取得できるM1確定足の全履歴を一括で書き出します
- その後はM1足が1本確定するたびに1行ずつ追記します
- 最後に書き出した足の時刻を状態ファイルに保存するため、MT4を再起動しても重複や抜けは出ません

## 導入手順

1. MT4で「ファイル」→「データフォルダを開く」を選びます
2. `MQL4\Indicators\` に `Indicators/M1HistoryLogger.mq4` をコピーします
3. MT4を再起動するか、ナビゲーターの「インディケータ」を右クリックして「更新」を選びます（MetaEditorで開いて「コンパイル」でも可）
4. 対象通貨ペアのチャート（時間足は何でも可）に `M1HistoryLogger` をドラッグします
5. 「全般」タブの **「DLLの使用を許可する」にチェック** を入れます（任意のドライブへ出力するために必要です）
6. 「パラメーターの入力」タブで出力先を確認して「OK」を押します

チャート左上に出力先・最終書き出し足・書き出し行数が表示されれば動作中です。

## パラメーター

| パラメーター | 初期値 | 内容 |
|---|---|---|
| 対象通貨ペア | 空欄 | 空欄のときはチャートの通貨ペアを使います。別の通貨ペアを指定することもできます |
| 任意フォルダへ出力(DLL使用) | true | trueのとき、下の「出力先フォルダ(DLL使用時)」へ出力します |
| 出力先フォルダ(DLL使用時) | `C:\MT4_M1_History` | ドライブ名から指定します。例：`D:\FXData\M1`、`G:\マイドライブ\MT4_M1_History` |
| 出力先フォルダ(DLL不使用時) | `MT4_M1_History` | DLLを使わないときの出力先です。`データフォルダ\MQL4\Files\` の中に作成します |
| 通貨ペアごとにサブフォルダを作成 | true | `出力先\USDJPY\` のように通貨ペア別のフォルダに分けます |
| ファイル分割単位 | 日別ファイル | 日別ファイル／月別ファイル／1ファイルに全て から選びます |
| 初回に書き出す最大本数 | 0 | 0のときは取得できる全履歴を書き出します。例：43200なら直近約30日分 |
| 区切り文字 | `,` | タブ区切りにしたいときは `\t` ではなくタブ文字そのものを入力してください |
| チャート左上に状況を表示 | true | 動作状況を表示します |

> DLLの使用が許可されていない場合は、自動的に `MQL4\Files\MT4_M1_History\` へ出力し、アラートでお知らせします。

## 出力ファイル

```
C:\MT4_M1_History\
└─ USDJPY\
   ├─ USDJPY_M1_20260921.csv
   ├─ USDJPY_M1_20260922.csv
   └─ _state_USDJPY_M1.txt   ← 最後に書き出した足の時刻（削除すると全履歴を書き出し直します）
```

CSVの形式（時刻はMT4のサーバー時間です）：

```
Date,Time,Open,High,Low,Close,Volume
2026.09.22,09:00,148.123,148.140,148.110,148.135,152
2026.09.22,09:01,148.135,148.150,148.120,148.128,98
```

- Volume はMT4のティックボリュームです
- ファイル名の日付は足のサーバー時間の日付です

## 注意点

- **Googleドライブへ保存したい場合**：「Google ドライブ パソコン版」をインストールすると `G:\マイドライブ` のようにドライブとして表示されるので、そのパスを出力先フォルダに入力してください
- **過去データを増やしたい場合**：MT4の「ツール」→「オプション」→「チャート」の「ヒストリー内の最大バー数」を増やし、M1チャートを開いて `Home` キーで過去をさかのぼって読み込ませてから起動してください。書き出せるのはMT4内にあるM1履歴だけです
- **同じ通貨ペアに2つ付けない**：同じ出力先・同じ通貨ペアで2つ動かすと、同じ行が2回書き込まれます
- **CSVをExcelで開いたままにしない**：Excelがファイルを占有して書き込みに失敗することがあります。失敗した分は次の足の確定時に自動で書き直します。見るときはコピーしてから開くか、メモ帳で開いてください
- 最初からやり直したいときは、出力先フォルダの `_state_<通貨ペア>_M1.txt` とCSVを削除してから付け直してください
