## 7. 現在の考え方(リスクと運用)

- **危険の本体は「押しを挟みながら何時間も続くトレンド」**。時間帯・曜日・月末月初の停止では防げない(バックテストで改善を確認できず)。週末停止は有効(週末は時間の5%で、80ドル級の一方向の動きの39%が始まる)。
- **金額の損切りに最適値は無い**。損切りした束は後でほぼ必ず戻っている。ただし今の資金では、損切りしないと強制ロスカットになる場面がある(09-28 は損切りしなければ含み損 約−44万円まで広がった)。損切りは「最後の安全装置」。
- 口座を守る主な手段は **口座額(入金)** と **動かすロジックを減らすこと**。最低ロット 0.1 は下げられない。
- 複数ロジックが同時に同じ方向で積むと、実質1つの束を何倍も持つ形になる(09-25 夜の a・b・c)。
- **資金 約1万円・許容損失50%では、20〜30ドルの一方向の動きで許容を超える**。この幅の動きは日常的に起きる(40ドル以上でも年約106回)。今の損切り設定(09-28 時点で10万円)は資金を超えており意味が無い → 設定額の見直しを Shinさんに提案済み(09-30)。
- **週末停止は必ずオン**(09-25 はオフにしていて −10万円の損切りになった)。
- 解析は「確定/有力/未特定」を分けて伝える。1分足で決められないことは「決められない」と言う。

## 9. MQL4・開発環境の技術ナレッジ

詳細は `EA開発ナレッジ.md`(4-1)。要点だけ。

- `#property strict` では `OP_BALANCE`(6)・`OP_CREDIT`(7)が未定義 → 自分で `#define` する。
- `Year()` などの引数付き呼び出しは無い(`TimeYear()` を使う)。`StringTrim()` は無い。`string&` に NULL を渡さない。
- 日本語のラベルは `MS UI Gothic` など日本語フォントにする(`Arial` は文字化け)。
- PowerShell の `Set-Content` は文字コードを指定しないと日本語が化ける → UTF-8 を指定するか、Claude Code の編集ツールで直す。
- XM の MT4 の MetaEditor は32ビット版(`metaeditor.exe`)。コンパイル: `metaeditor.exe /compile:"...mq4" /log`。
- 自動売買ボタンは MQL4 から直接操作できない。DLL(user32)で押す方式を EA_Monitor v3.0 で採用(DLL の許可が必要)。
- ソース非公開の EA(Ragnarok)には GlobalVariable の停止シグナルは効かない。
- 出金・クレジットでドローダウンが狂う → 入出金を差し引いた有効証拠金で計算する。
- VPS はリセットされることがある。重要なファイルは同期フォルダ(Drive)にも置く。
- EA として動かすには `OnTick()` が必要(処理はタイマーで行う設計)。
- ティックごとにファイルを開くと重い → メモリにためてまとめて書く(v3.9)。
