## 2. grid_step_pts の正体(旧メモ2.5の課題)

仮説「grid_step_pts = |今回OPEN価格 − 同じmagicで直前にOPENした注文の価格| × 100」を全84件で検証した結果、**83件が±1pts以内で一致**しました。

- 同じmagicの直前注文には、**別グリッド(a/b/c)の注文も含まれます**。
  - 例: c売り(14:38開始)の grid_step_pts は `3, 1, 0, 0, 7, 1, 0, 73, 157`。b売りとほぼ同時・同価格で建っているため、ほぼ0になっています。
- 不一致の1件(18:57:01 c_0)は、直前の注文がログから漏れていることが原因と推定されます。

**結論: grid_step_pts はATR等とは無関係なモニター側の計算値です。ラグナロクのロジック解析には使いません。**

## 3. ナンピン条件(旧メモ2.4の課題)

### 3.1 最短間隔 = 420秒
全59件のナンピン間隔の分布:
- 419〜428秒: 38件(64%)
- 438〜441秒: 2件
- 452秒以上: 19件(逆行幅不足による待ち、3.3節の未解明の待ち、ログ欠落による見かけの待ち)

→ **「直前レグから7分(420秒)経過するまでナンピンしない」はほぼ確定**です。

### 3.2 最小逆行幅 ≈ 100〜120pts
ナンピン時点の逆行幅(直前レグの価格から、不利方向に何pts動いたか。bidで計測。M1データがある20:27までの52件):
`105, 112, 117, 118, 121, 121, 123, 124, 124, 129, 131, 134, 144, 145, 148, 148, 150, 161, 173, 178, 182, 192, 194, 197, 202, 202, 226, 244, 251, 273, 292, 295, 296, 318, 321, 324, 334, 340, 354, 366, 371, 379, 393, 399, 415, 447, 514, 516, 609, 829, 861, 1263`

- 最小は105pts。100pts未満でナンピンした例はありません。
- 7分経過時点で逆行幅が足りない(あるいは含み益側にある)場合は、条件を満たすまで待ちます。
  - 例: a買い leg3 → 12:17は−262、12:18は−262、12:19に+69→134ptsになった時点でエントリー。
  - 例: c売り leg5 → 15:13は−220、15:14は−66、15:15は−35、15:16に105ptsになった時点でエントリー。

### 3.3 まだ説明できない「待ち」
7分経過し、逆行幅も十分なのにナンピンしなかったケースが残っています。

| バスケット | 待機区間 | 待機中の逆行幅 | 実エントリー |
|---|---|---|---|
| b/c売り leg5/6 | 15:23〜15:26 | 1182〜1468pts(急騰中) | 15:26:47 |
| b/c売り leg6/7 | 15:33〜15:43 | 450〜735pts | 15:43:59 / 15:44:00 |

検証して**否定された**条件:
- 3分モメンタムの反転(close[i]−close[i−3]の符号): 15:33は有利方向なのにエントリーしていない
- M1足レンジの縮小: 15:33〜15:43の足のレンジは171〜542ptsで、エントリーした15:44の足(511pts)のほうがむしろ大きい
- 直近の極値からの戻り幅: 戻り幅は1〜859ptsでばらつき、一定値が無い

**未解明**です。急騰急落中に止まる何らかのフィルター(M5/M15の指標、ティック単位の条件など)があると推定されます。

### 3.4 補足: 18:37〜19:03の「26分待ち」はログ欠落

## 4. 初弾の方向ルール(旧メモ2.1の再検証)

全83件の初弾(`_0`)を、M1足で「エントリー時のbid − (エントリー分 − k分)の足の終値」の符号で判定しました。

| 比較対象 | a | b | c |
|---|---|---|---|
| M1 k=1 | 5/7 | 24/45 | 13/28 |
| M1 k=2 | 5/7 | 35/46 | 17/29 |
| **M1 k=3** | 5/7 | **44/46 (96%)** | 21/30 |
| M1 k=4 | 5/7 | 39/46 | 19/30 |
| M1 k=6 | 5/7 | 22/46 | 22/30 |
| M5 直前確定足の終値 | 5/7 | 36/45 | 21/30 |
| M15 2本前の終値 | 7/7 | 29/46 | 13/30 |
| M15 直前足の陽線/陰線 | 7/7 | 26/46 | 9/30 |

- **bグリッド**: 「現在値がk=3の足(例: 20:17エントリーなら20:14の足)の終値より高ければ買い、低ければ売り」で96%一致。旧メモのルールと同じ内容です。
- **cグリッド**: どの比較でも最大73%。**bとは別のロジック**と考えるのが妥当です(旧メモの2件一致は偶然の可能性)。
- **aグリッド**: 7件しかなく判定できません。M15系で7/7ですが、サンプル不足です。

**初弾のタイミング**も未解明です。バスケットが無く、モメンタムが十分(±200pts以上)の分が多数あるのに、エントリーしていません。方向を決める条件とは別に、発火条件があります。

## 6. 更新後のモデル(バックテスト用の仮仕様)

```
[グリッド] a / b / c の3系統 × 買い・売り独立 = 最大6バスケット
[初弾]     方向: bid vs 3本前M1足の終値(bで96%一致。a/cは未確定)
           タイミング: 未解明
[ナンピン] 条件: 直前レグから420秒以上 かつ 直前レグ価格から100pts以上逆行
           ロット: 直前×1.5(0.10→0.15→0.23→0.34→0.51→0.76→1.14→1.71→2.56→3.84)
           上限: NanpinCount=40(実測最大は10レグ)
           未解明フィルター: 急騰急落中は見送り(3.3節)
[利確]     1レグ: 加重平均建値から+70pts / 2レグ以上: +140pts で全レグ一括決済
```

実測最大はc売り(14:38開始)の10レグ、合計11.34lot、決済まで約1時間46分(記録上の利益+3,331円。c_4のCLOSEが記録漏れのため実額は不明)です。10レグで初弾の約113倍のロットになるため、ドローダウンの耐性試算が最優先です。
