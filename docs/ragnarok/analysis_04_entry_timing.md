# ラグナロク a / b / c 初弾タイミング解析 — 第4回

データ:
- `ea_monitor.csv`: 2026.09.22 10:36 〜 09.23 07:17(サーバー時間)。初弾(`_0`)は a 25件 / b 68件 / c 46件。
- M1足: GOLDmicro(〜09.22 20:27)＋GOLD(〜09.23 07:17)。

## 0. 結論

| 項目 | a | b | c |
|---|---|---|---|
| 判定するタイミング | **5分足の始値**(:00/:05/:10…の0〜3秒)。25件中17件。例外は、直前のバスケット決済から0〜2秒後など | **1分足の始値**(0〜3秒)。68件中66件 | **1分足の始値**(0〜3秒)。46件中46件 |
| 方向ルール(現在値 vs k分前のM1終値) | **k=20で23/23(100%)**。k=17〜23で22〜23/23 | **k=3で63/68(93%)** | **k=11で41/46(89%)** |
| 同じ方向の初弾どうしの最短間隔 | 7.6分(例外1件: 3.5分) | **6.0分**(5.98〜6.02分が下限) | **9.0分**(9.00〜9.02分が下限) |
| まだ特定できていない条件 | 下の2章 | 同左 | 同左 |

3系統は同じ仕組みで、次の3つのパラメーターだけが違うと考えられます。
- 比較する時間(a=20分、b=3分、c=11分)
- 判定する足(a=M5、b/c=M1)
- 同方向の再エントリー間隔(a≒7.5分、b=6分、c=9分)

## 1. 確定・ほぼ確定したルール

1. **方向**: 「今のbid > k分前のM1終値」なら買い、「<」なら売り。
   - kの値: a=20、b=3、c=11。
   - 前回、aは件数不足で判定保留でしたが、売り5件を含む23件で100%一致しました。
2. **判定タイミング**:
   - b/c: 1分足が始まった直後の最初のティック。
   - a: 5分足が始まった直後。ほかに、自分のバスケットが決済された直後(0〜2秒後)にも入ることがあります(02:36:53、03:29:19、03:37:29など)。
3. **同方向の再エントリー制限**: 同じグリッド・同じ方向の初弾は、前回の初弾から b は6分、c は9分以上空けます。下限ちょうどの例が複数あるため、ほぼ確定です。

## 2. 未解明: 「方向は出ているのに入らない足」

1〜3の条件をすべて満たすのにエントリーしなかった足が、多く残っています。

| | 満たした足(クールダウン後) | 実エントリー |
|---|---|---|
| b | 419 | 63 |
| c | 583 | 40 |
| a | 171 | 23 |

→ 追加の発火条件があります。検証結果は次のとおりです。

| 候補 | 結果 |
|---|---|
| シグナルの強さ(k分前との差の大きさ) | 判別できない(AUC 0.43〜0.55) |
| 直前の足の実体・レンジ・出来高、N本高安値のブレイク | 判別できない(AUC 0.38〜0.58) |
| RSI(M5/M15/H1)、MA20からの乖離 | 入った足と見送った足で分布がほぼ同じ |
| 前回決済からの経過時間 | 弱い差(b/c AUC 0.63)。aだけは強い(AUC 0.22: 決済直後に入りやすい) |
| **M1ストキャス(9,3,3)の%K/%Dが方向どおりクロスした直後** | **b: 入った足の49% vs 見送った足の13%(約3.7倍)** |
| **M1のMA10/MA20が方向どおりクロスした直後** | **c: 入った足の23% vs 見送った足の2%(約11倍)** |
| M5ストキャス%Kが50を方向どおりにクロス | a: 入った足の22% vs 見送った足の7% |

→ **グリッドごとに異なる「クロス系のトリガー」が、方向ルールに加わっている可能性が高い**です。ただし単独では、エントリーの半分以下しか説明できません。
