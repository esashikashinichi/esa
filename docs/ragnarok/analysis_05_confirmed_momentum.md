# ラグナロク 確定足モメンタム(N本前比較)の検証 — 第5回

データ: `ea_monitor.csv`(〜2026.09.23 07:17)、M1足(GOLDmicro〜09-22 20:27＋GOLD〜09-23 07:17)。M5はM1から合成。
判定式: `sign(Close[1] − Close[1+n])`(Close[1]=直前の確定足。形成中の足は使わない)

## 0. 結論

- 旧メモ・EA_Monitor仕様書には「確定足◯本前モメンタム」の記述は**無い**。唯一の関連記述は、セッション1のメモ2.4「3分モメンタム(close[i]−close[i−3])のエッジ検知ではズレが大きい」のみ。
- **方向の判定には効く**: b は M1 の Close[1] と Close[3] の比較で 64/68、a は M5 の Close[1] と Close[5] の比較で 24/25。
- **c は確定足モメンタムでは説明できない**: 最良でも 35/46(76%)。bid と11分前の終値の比較(41/46)のほうが上。
- **タイミング(いつ入るか)は説明できない**: 符号が有利側に反転した足(エッジ)でのエントリー率は、b 15〜30%、c 4〜8%、a 11%。条件が成立していても大半の足で見送られている。

## 2. タイミング検証(クールダウン明けの候補足のみ)

候補足の条件: グリッドが空いていて、判定タイミング(b/c=M1の始値、a=M5の始値)に当たり、同方向のクールダウン(b 6分、c 9分、a 7.5分)が明けていること。

- → 確定足モメンタムは**方向フィルター**。発火条件は別にある(第4回の候補: b=M1ストキャスのK/Dクロス、c=M1 MA10/20のクロス)。
