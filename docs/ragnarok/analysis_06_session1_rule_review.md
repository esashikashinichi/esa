# セッション1「3分モメンタム」ルールと再現コードの検証 — 第6回

対象:
- セッション1の「3分モメンタム」ルールの定義(Shinさんが貼り付け)
- セッション1の再現コード。原文のまま `tools/ragnarok/legacy/backtest_ragnarok_abc_session1.py` に保存

データ: `ea_monitor.csv`(〜2026.09.23 07:17)の初弾139件、M1足(GOLDmicro＋GOLD)

## 0. 結論

- 「3分モメンタム」は **bグリッド専用の方向ルール**。63/68(93%)で一致する。
- aとcには当てはまらない(a 17/25、c 31/46)。セッション1の「4/4」のうち2件はcで、偶然の一致だった。
- **再現コードには1本ずれがある**。`close[i] − close[i−3]` は20:16足で判定すると20:13足と比べる形になり、定義(20:14足)より1本古い。定義どおりなら `close[i] − close[i−2]`。一致数は64/68(ずれたままだと58/68)。

## 1. 定義どおりの一致数(判定の瞬間のbid − 3本前のM1足の終値)

| グリッド | 一致 | そのグリッドの最良ルール |

| **b** | **63/68** | このルール(確定足の Close[1]−Close[3] なら 64/68) |
| c | 31/46 | bid と11分前のM1足の終値の比較 41/46 |
| a | 17/25 | bid と20分前のM1足の終値の比較 23/23 / M5の Close[1]−Close[5] 24/25 |

## 2. 定義の文言の訂正

- 「3分前に**確定した**1分足の終値」→ 正しくは「**3本前の**1分足の終値」(MT4の `iClose(M1,3)` / `Close[3]`)。
  - 20:17:00時点では Close[0]=20:17(形成中)、Close[1]=20:16、Close[2]=20:15、Close[3]=20:14。
  - 20:14足が確定するのは20:15:00(判定の2分前)。
- 確定足どうしの比較(`Close[1] − Close[3]`)でも64/68で、結果は同じ。バックテストではこの形でよい。

## 3. 再現コードと検証済みルールの差分

| 項目 | セッション1のコード | 検証済みのルール(第2〜6回) |
|---|---|---|
| 初弾の方向 | a/b/c共通で `close[i]−close[i−3]` | b: `close[i]−close[i−2]`(3本前)/ c: 11分前 / a: 20分前(M5なら Close[1]−Close[5]) |
| 判定する足 | 全グリッドとも毎分 | b/c: M1足の始値 / a: M5足の始値 |
| 同じ方向の再エントリー間隔 | なし(決済直後に即再エントリー) | b 6分 / c 9分 / a 約7.5分 |
| 初弾の発火条件 | 方向が合えば必ず入る | 方向・判定する足・間隔の3条件を満たしても、大半の足で見送る(未特定) |
| ナンピンのタイミング | モメンタムの符号が逆に転じたとき(エッジ) | 直前レグから420秒以上 かつ 約100pts以上の逆行 かつ 相場全体の待機フィルター(未特定)。エッジ説は否定済み |
| ナンピンのロット | 常に×1.5 | ×1.5。11レグ目以降は×1.2 |
| 利確幅 | 全て140pts | 1レグ約70pts / 2レグ以上約140pts。大ロットでは50〜75ptsで決済された例あり(条件は未特定) |
| grid_step_pts | 未確定扱い | EA_Monitorが計算した値(同じmagicの直前注文との価格差)。ラグナロクのロジックとは無関係 |
| 価格 | closeのみ(スプレッド無し) | 買いはask、売りはbidで約定。スプレッドの考慮が必要 |
| M1_PATH | セッション1のuploadsのパス(現在は存在しない) | Drive `EA解析/GOLD` のM1データに差し替えが必要 |

「a/b/cの初弾がずれて入る理由」(コード内の未確定事項)への回答:
- 比較する時間(3/11/20分)、判定する足(M1/M5)、再エントリー間隔(6/9/7.5分)がグリッドごとに違うこと。
- 残る未特定の発火条件。

## 4. 修正版ルール(バックテスト用の仕様)

```
[初弾の方向] プラスなら買い、マイナスなら売り
  b: Bid − iClose(M1,3)            (確定足で Close[1] − Close[3] でも可)
  c: Bid − 11分前のM1足の終値
  a: Bid − 20分前のM1足の終値       (M5の Close[1] − Close[5] でも可)
[判定する足]         b/c = M1足の始値、a = M5足の始値
[同じ方向の再エントリー間隔] b 6分 / c 9分 / a 約7.5分
[初弾の発火条件]     未特定
[ナンピン]           420秒以上 かつ 約100pts以上の逆行 かつ 待機フィルター(未特定)
                     ロット×1.5、11レグ目以降×1.2、上限 NanpinCount=40
[利確]               1レグ +70pts / 2レグ以上 +140pts(加重平均建値から)
```
