# 解析08: m1stateログ(毎分の指標)による手がかり


- データ: ea_monitor_m1state.csv(09-23 09:51〜18:48 サーバー時間、535行)、ea_monitor.csv(同期間 OPEN 85件 / CLOSE 89件)。時刻はサーバー時間(ローカル=サーバー+6時間)。

### K-1. ナンピン条件(29件)
- 時間条件: 前レグから**420秒**で確定。29件中17件が420〜424秒で即発動。
- 最小刻み幅: **約110pts**(前レグ建値からAsk/Bidで測定)。未達の間は待ち、110〜130ptsに届いた瞬間に発動(b_5=110、b_9=119、b_7=120、b_2売り=118)。
- 逆行幅の上限は**無い**。520/540pts逆行でも420秒で即発動(14:36 b_1買い、15:39 b_2買い)→「急落中はナンピンしない」説は否定。
- 未解明の待機: 5件(10:17開始のb買いバスケットのb_2,b_3,b_4,b_6,b_7)。時間OK・逆行110〜650ptsなのに3〜13分発動せず。解除時3件は上向き(足始値比 +36/+153/+73pts)→**反発確認(底打ち待ち)**が候補。1分スナップショットでは検証不可。

### K-2. 早期利確
- 2段以上の決済幅は二極化: 通常 約130〜150pts / 早期 約35〜80pts。
- 利益が一度決済幅より大きくなってから戻って決済した例: 12:24 c買い(足始値+92→7秒後+35)、11:30 b売り(+65→+46)、14:18 b売り(+85→+56)→**利益到達後の戻りで決済(トレーリング/利益確保)**が有力。
- 同方向の別ロジック連動らしき例: 06:55:01 a買い通常利確(145)→14秒後b買い(78)、09:49:20 c買い(128)→26秒後b買い(76)、01:29:01 a買い→1秒後b買い(-54、損失)。単独の早期決済(15:21 b売り65等)もあり、連動だけでは説明不可。
- **損失決済**: 08:20:19 b売り4本(b_0,b_1,b_3,b_4。b_2無し)を-375pts/-653円で決済、同時にb_0売り新規。通常TPではない。原因不明(要調査、リスク上重要)。

### K-3. 初弾の発火条件
- b=M1ストキャス(9,3,3)K/Dクロス: 12/29(ランダム足の基準21%)→単独の発火条件ではない(否定寄り)。
- c=MA10/MA20クロス: 5/24 →**否定**。

### K-4. 新規エントリーの停止
- 最後の新規(初弾)は15:28:01、再開は18:36:01(サーバー時間)。自動売買ONのまま約3時間、新規0件。前日の同時間帯は稼働。
- **経済指標フィルターでほぼ説明できる**: 起動ログのパラメータ `ShihyoCountryUSA=0; ShihyoRate=2; StopMin=120; StartMin=60; EntryStop=true`。指標時刻をサーバー17:30(=UTC 14:30=米東部10:30、水曜のEIA原油在庫の時刻)とすると、停止開始15:30(120分前)・再開18:30(60分後)。実測の15:28〜18:36と一致(再開後の最初の初弾は、bの判定タイミング待ちで18:36)。
- 停止中も既存バスケットのナンピン(15:32 b_1、15:39 b_2)と利確(15:59)は継続 →**止まるのは新規の初弾だけ**。
- 当日の指標カレンダーとの照合は未実施(サーバー=UTC+3はログのローカル時刻差からの推定)。
