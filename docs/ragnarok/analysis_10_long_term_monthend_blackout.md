# 解析10: M15足2.2年の検証、月末月初、新規停止のバックテスト

- データ:
  - GOLDmicro M15足 2024-07-23〜2026-09-21(約2.2年、50,964本)。Drive `EA解析ログデータ/GOLD/GOLDmicro15.csv`
  - バックテスト用M1足: GOLD 2026-07-17〜09-02 ＋ GOLDmicro 09-03〜09-23(67.7日)
- 時刻は日本時間。夏時間(3月第2日曜〜11月第1日曜)はサーバー+6時間、冬時間は+7時間で換算。
- 価格が2年で約2,400→4,700ドルに上がったため、M15の長期比較は**%で判定**。0.70% ≒ 現在の30ドル、1.16% ≒ 50ドル、1.8% ≒ 80ドル。
- スクリプト: `tools/ragnarok/m15_long.py`、`monthend.py`、`trend_days.py`、バックテスト `backtest_ragnarok_abc_v2.py`(`--block` / `--month-stop` を追加)

## 0. 結論

1. **2.2年でも、曜日・時間帯の傾向は5か月の結果と同じ**。危ないのは日本時間21〜24時(NY)と7〜10時、静かなのは2〜6時。曜日は木が最も荒い。
2. **月末月初は「やや荒い」程度**。月内の普通の日と比べた値幅は平均1.17〜1.29倍(通常日1.06倍)。ただし中央値はほぼ同じ(1.00〜1.07倍)で、**ときどき大きく動く日が混じる**という形。各26日しか無く、差ははっきりしない。
3. **ボラティリティは2025年後半から大きく上がった**。3時間で0.70%以上動く時間は、2024〜2025年前半の5〜9% → 2026年は25〜44%。**過去2年の平均より、直近の相場のほうがずっと荒い**。
4. **バックテストでは、時間帯の新規停止(水木金20〜24時)も月末月初の停止も、口座を守れなかった**。モデルのロスカットは、9〜16時間かけて一方向に80〜175ドル動く「トレンド日」に起きており、時間帯の停止では避けられない。
5. トレンド日(12時間で片方向1.8%以上)は直近の四半期で**2日に1日**(49〜68%)。月末月初はやや多い(38〜46%、通常日32.5%)。

## 3. バックテスト: 新規の初弾を止めた場合(67.7日、口座180,901円)

条件: 上限レグ40/12/10 × 発火 always と prob(seed 0〜4) = 18通り × 4パターン。

| パターン | 耐えた数(18通り中) |
|---|---|
| 停止なし | **4** |
| 水木金の20〜24時に新規停止 | 1 |
| 月末月初(各1営業日)に新規停止 | 3 |
| 両方 | 1 |

- **停止しても改善しなかった**。見送った初弾の分だけ利確が減り、その後の値動き次第で結果が入れ替わる(乱数の違いと同程度の差)。
- モデルのロスカットは、次の4つの「トレンド日」に集中した(日本時間)。

| ロスカット時刻 | 値動き |
|---|---|
| 07-21(火) 14:40〜15:41 | 07-20 7時〜07-21 16時に +78ドル(3,982→4,084)。東京〜欧州時間の上昇 |
| 07-23(木) 21:48〜22:04 | 同日7時〜22時に −90ドル(4,141→4,040) |
| 08-05(水) 23:05〜23:10 | 同日7時〜23時半に +175ドル(4,065→4,241) |
| 08-11(火) 09:24〜09:25 | 前日22時〜翌10時に +87ドル(4,317→4,419) |

- いずれも**9〜16時間かけて一方向に80〜175ドル動いた日**で、始まりは20〜24時とは限らない。時間帯の停止ではこの型を避けられない。
- 注意: このモデルにはナンピンの待機フィルター(未特定)が無く、実機よりナンピンが多い(解析07)。実機はこれらの日を耐えている可能性がある。**「停止が無意味」ではなく「このモデルでは効果が確認できない」**という結論。

## 4. 示唆

- 危険の本体は「時間帯」ではなく「**トレンド日**(長時間の一方向)」。直近は2日に1日ある。
- 対策の候補は、時間帯よりも**値動きそのものに反応する停止**:
  - その日の始値(日本時間7時)から一定幅(例: 40〜60ドル)以上動いたら、逆方向の新規を止める。
  - 上位足のトレンド(H4のMAの傾きなど)に逆らう方向の新規を止める。
  - これらはEA_Monitor側でも判定できる(自動売買ボタンのOFF、またはTelegramで警告)。
- 月末月初の停止は「やや荒い日を避ける」効果はあるが、決定的ではない。現行の月末月初停止(EA_Monitor)は維持でよい。
