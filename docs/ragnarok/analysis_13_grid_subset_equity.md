## 2. 読み取り

- **ロジックを減らしても、口座18万円ではほとんど改善しない**(6通り中0〜3)。1つのロジックの1バスケットだけで、ナンピン上限40まで進むと口座を超える含み損になるため。
- 口座額の効果の方が大きい。90万円(0.02・18万円と同じ比率)では、3ロジックで5/6、1ロジックで6/6。
- ロジックを減らすと利確も減る(90万円の残高増: 3ロジック+160万円、bのみ+84万円、aのみ+32万円)。
- ロスカット日は、どの組合せでもほぼ 07-21、08-05、08-11(トレンド日)。
- 30〜50万円では b+c、cのみ が比較的強いが、6通りの差でありモデル誤差の範囲。

## 3. 結論

- 最低ロット0.1のままでは、**口座を守る主な手段は口座額**。現在の3ロジックで耐える目安は約90万円(この67.7日・このモデルで6通り中5通り)。
- ロジック数を減らすのは、口座額を増やせない場合の補助。効果は小さく、利益も減る。
- 注意: モデルはナンピンの待機フィルターが無く、実機よりナンピンが多い。待機フィルターが特定できれば、必要な口座額はこれより下がる可能性がある(実機は09-23の局面をモデルより少ないレグで耐えた。解析07)。
