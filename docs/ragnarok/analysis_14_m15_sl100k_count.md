# 解析14: M15足2.2年で、10万円の損切り(バスケット単位)は何回発動するか

- データ: GOLDmicro M15足 2024-07-23〜2026-09-21(2.16年)。
- スクリプト: `tools/ragnarok/m15_sl_count.py`(バックテストv2・sl_study のルールをM15足に近似)
- 条件: 初弾0.10、バスケット単位で含み損10万円に達したら決済。口座の証拠金・ロスカットは見ない(口座が十分にある前提で、発動回数だけを数える)。
- 初弾: always(条件を満たせば必ず入る)と prob(実測の発火率、seed 0〜4)の6通り。以下の数字は prob 5通りの中央値。
- ナンピン上限: 40(実機の設定)と 12(実測の最大。待機フィルターでレグ数が止まる場合の目安)。

## M15足への近似と確認

- 初弾の方向は「足の始値 − 15分前の終値」(a/b/c共通)。ナンピンは1本(15分)に最大2回(420秒×2)。
- 重なる期間(2026-07-17〜09-21)で、M1足モデルと損切り回数を比べた(上限40):
  - prob: M15近似 18〜21回 / M1モデル 15〜25回 → ほぼ一致
  - always: M15近似 27回 / M1モデル 42回(M1の方が初弾が多い)

## 1. 結果

| | 上限40(実機の設定) | 上限12(実測の最大) |
|---|---|---|
| 2.16年の損切り回数 | **249回** | **186回** |
| 1年あたり | 約115回 | 約86回 |
| 損切りが起きた日数 | 107日(週に約1日) | 82日 |
| 1日の最多 | 6回 | 5回 |
| 損切りの合計 | −2,490万円 | −1,864万円 |
| 同じ期間の利確の合計 | +1,211万円 | +961万円 |
| 損切りしたバスケットが後で利確まで戻った割合 | 100% | 84% |
| 戻るまでの時間(中央値) | 約1時間 | 約36時間 |
| 損切り時のレグ数(中央値) | 18 | 12(上限) |

四半期ごとの回数(中央値):

| 四半期 | 上限40 | 上限12 |
|---|---|---|
| 2024Q3(7/23〜) | 20 | 10 |
| 2024Q4 | 25 | 19 |
| 2025Q1 | 37 | 17 |
| 2025Q2 | 40 | 34 |
| 2025Q3 | 18 | 27 |
| 2025Q4 | 29 | 21 |
| 2026Q1 | 29 | 33 |
| 2026Q2 | 20 | 11 |
| 2026Q3(〜9/21) | 27 | 15 |

- 損切りが1回も無い月は、27か月中 上限40で0か月、上限12で1か月。静かだった2024年後半も、四半期に10〜25回。
- 損切りの合計が利確の合計の約2倍。10万円の損切りを入れると、2年通して大きなマイナスになる。
- 上限40では、損切りしたバスケットは全て戻っていた(中央値1時間後)。10万円に届くのはレグ数が18前後まで増え、平均建値が現在値に近い時で、少し戻れば利確になる。
- 上限12では16%が戻らなかった(レグが止まり、平均建値が下がらないため)。

## 2. 10万円の含み損は何レグ・何ドルか(目安)

一定方向に逆行し、100ptsごとにナンピンした場合(実機は間隔が空くため、同じ値幅ならレグ数はもっと少ない):

| レグ数 | 合計ロット | 含み損(次のナンピン直前) |
|---|---|---|
| 10 | 11.34 | −6,013円 |
| 12 | 21.49 | −12,769円 |
| 15 | 45.67 | −32,122円 |
| 18 | 87.45 | −69,596円 |
| 20 | 131.09 | −110,827円 |

- 1バスケットで10万円は、約20レグ・約20ドルの逆行に当たる。実機でこれまで見た最大は12レグ。

## 3. 注意

- モデルにはナンピンの待機フィルターが無く、実機よりナンピンが多い。実機の回数は、上限12の結果(年86回)に近いか、それより少ない可能性がある。
- M15足の中では高値・安値のどちらが先かが分からない。同じ足の中は「初弾 → 利確 → ナンピン → 損切り」の順で処理した。
- 口座の証拠金を見ていない。口座18万円では、最初の数回の損切りで口座が無くなる(解析12)。
