- スクリプト: `tools/ragnarok/calib_3days.py`(M15足の近似は `m15_sl_count.py`。今回、経済指標停止の近似 `--news` をM15版にも入れた)
- 条件: 初弾0.10、ナンピン上限40、損切りなし、経済指標停止あり。初弾は実測の発火率でランダム(5通り、以下は中央値)。

## 3. 読み取り

- 実機の3日間(最大 −4.8万円)は、2年の中では**普通の日〜やや悪い日**の水準(30%の日が5万円を超える)。
- 実機に合わせても、**含み損が口座(約17〜20万円)を超える局面は2年で約57回**起きる計算。2024年後半の静かな時期でも四半期に2〜4回、2025年春以降は四半期に6〜12回。
- 元のモデルより危険な日は4割ほど減るが、「週に1〜2回は5万円超、2週間に1回は16万円超」という形は変わらない。
- 決済益も元のモデルの約半分(1日 +9,000円前後)になり、3日間の実績(9/23 約+2万円)より少ない。

## 4. 注意

- 合わせ込みに使えたのは実質1.5日分。この間に「長時間戻らない一方向の動き」は無く、その場面で待機フィルターがどう働くかは確認できていない。実機がもっと強くナンピンを止めるなら、危険な回数はこれより少ない。
- 含み損は足の最悪値(買いは安値、売りは高値)で見ている。1分足での推定は実際より2〜5%大きい程度だった(解析16)。
- 口座の証拠金を見ていないため、16万円を超えた後もバスケットが続く(最悪値は非現実的な数千万円になる)。回数だけを見ること。
- 確かめる方法: Ragnarokを実口座で動かしてきた期間とロスカットの有無が分かれば、この年26回という数字と直接比べられる。
