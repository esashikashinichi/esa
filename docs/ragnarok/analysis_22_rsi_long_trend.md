# 解析22: トレンドがずっと続くと、RSI の待機はどうなるか

- Shinさんの問い: 一定方向にトレンドが続くと RSI はずっと上に行くと思う。それがずっと続く場合はどうなるか。
- 前提(解析21の4節): ナンピンは、逆行側の M5 RSI が高い間は入りにくい(75超 0/6、70〜75 17%、60〜70 24%、50〜60 66%、50以下 100%)。
- データ: GOLDmicro M5足 2026-04-13〜09-21(31,679本)。スクリプト `tools/ragnarok/rsi_trend_runs.py`。

## 1. M5 RSI(14) は高いまま張り付かない

| しきい値 | 超えている時間の割合 | 連続して超えている長さ(中央値 / 90% / 最長) |
|---|---|---|
| 70 | 4.8% | 10分 / 40分 / 155分 |
| 75 | 2.0% | 10分 / 約36分 / 110分 |
| 80 | 0.7% | 10分 / 30分 / 50分 |

- 75超が続くのは、ほとんどが10〜40分。5か月で最長でも110分。

## 3. 結論

- 長いトレンドでも RSI は途中で何度も下がるため、**待機はナンピンを「遅らせる」だけで「止める」ことはできない**。押しのたびに入り、段数は増えていく(間隔が広がるだけ)。
- 09-22 夜の b売り(12段 21.49ロット)も、待機を挟みながら積み上がった例。
- 12段まで積むと合計 21.49ロット。平均建値からさらに10ドル逆行すると約 −3.4万円(1ロット×1ドル≒157円)。3ロジックが同じ方向に積むと、この2〜3倍になる。
- 危ないのは「RSI が張り付く急騰」より、「押しを挟みながら何時間も続くトレンド」。戻り10ドル未満で60ドル以上動く相場は年約29回(解析ノートV節)。待機フィルターは、この型を防げない。
