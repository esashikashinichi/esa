# 解析24: 1ロジックだと何ドルの逆行に耐えられるか

- Shinさんの問い: 1ロジック(b だけ)だと、何ドルくらい耐えられそうか。
- 前提: 今の有効証拠金 111,454円(残高 44,149円+クレジット 67,305円)。スクリプト `tools/ragnarok/one_logic_tolerance.py`。
  - ロットは 0.10 から ×1.5(10段目 3.84)、11段目から ×1.2。上限40段。
  - 戻りが無いまま逆行が続き、一定の間隔ごとにナンピンが入ると仮定。
  - 1ロット×1ドル = 157.6円(09-25 の実決済から逆算)。証拠金は1ロット 657円、維持率20%でロスカット。

## 1. ナンピンの間隔ごとの答え(初弾からの逆行幅)

| ナンピンの間隔 | 例 | 含み損 −5万円 | 含み損 −10万円 | 強制ロスカット(維持率20%) |
|---|---|---|---|---|
| 1.1ドル(最小) | 待たずにじわじわ上がり続ける | 17.9ドル(17段) | — | **20.9ドル**(20段) |
| 2.0ドル | 実機3日間の平均に合わせた値(U節) | 28.6ドル(15段) | 33.8ドル | **34.0ドル**(17段) |
| 3.0ドル | | 39.2ドル(14段) | 46.2ドル | **46.6ドル**(16段) |
| 3.8ドル | 09-25 夜の b の実際の平均間隔 | 47.0ドル(13段) | 55.4ドル | **56.2ドル**(15段) |
| 5.0ドル | | 58.0ドル(12段) | 68.6ドル | **69.7ドル**(14段) |

- 今の資金では、−10万円とほぼ同時に強制ロスカットになる(10万円の損切り設定は、実質もう意味が無い)。1.1ドル間隔では −10万円に届く前に強制ロスカット。
- 目安: **約35〜55ドル**。じわじわ待たずに積む最悪の形では約21ドル。
- 09-25 夜の b は約44ドルの上昇で10段・最大含み損 約−2.6万円(間隔が広く、待機が効いた)。

## 3. どのくらいの頻度で来るか

- 戻り10ドル未満のまま一方向に動く相場(解析ノートV節、M15足2.16年): 40ドル以上・3時間以上が年約106回、60ドル以上が年約29回、80ドル以上が年約8回。
- 大きな束は8〜10ドルの戻りで利確することが多いので、「戻りの無い40〜60ドル」が1ロジックの危険ラインに当たる。
- 注意: 実際の間隔は待機の効き方で変わる(09-25 夜の b は 1.3〜11.4ドル、中央値 約1.8ドル・平均 約3.8ドル)。証拠金不足で発注できない段は考慮していない。
