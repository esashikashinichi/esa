# 解析25: ナンピンの待機は M1 と M5 の RSI の両方を見ているか

- Shinさんの問い: 逆行の時に、M1 と M5 の RSI の両方を見ているということは無いか。
- データ: EA_Monitor の毎分記録(m1state)09-23 09:51 〜 09-25 15:48(サーバー時間)。09-25 夜の10段ナンピンも含む。スクリプト `tools/ragnarok/nanpin_wait_rsi_m1m5.py`。
- 方法: 時間(420秒)と値幅(110pts)の条件が揃っている分を取り出し、次の1分でナンピンが入ったかを数えた。a・b・c は同じ秒で待ち・入るため、同じ分・同じ方向は1件にまとめた(359件、うち入った85件)。RSI は逆行側から見た値(売りの束はそのまま、買いの束は 100 − RSI)。

## 1. 結果: M5 × M1 の表(入った数 / 件数)

M1 RSI は次の分の記録の値(入った瞬間に近い値)。

| 逆行側 M5 RSI | M1 50以下 | M1 50〜60 | M1 60超 | 合計 |
|---|---|---|---|---|
| 50以下 | 10/10 | 13/13 | 4/4 | **27/27(100%)** |
| 50〜60 | 4/4 | 11/19 | 15/21 | 30/44(68%) |
| 60〜70 | 2/8 | 11/42 | 8/114 | 21/164(13%) |
| 70〜75 | 2/4 | 4/18 | 1/61 | 7/83(8%) |
| 75超 | 0/1 | 0/7 | 0/33 | **0/41(0%)** |

- M5 RSI 60〜75 の中間帯: **M1 RSI 60以下なら 19/72(26%)、60超なら 9/175(5%)**。M1 が下がっている時のほうが約5倍入りやすい。
- M5 RSI 50以下: M1 に関係なく全て入った(M1 60超でも 4/4)。
- M5 RSI 75超: M1 が50以下でも入らなかった(0/1、0/7)。

## 2. しきい値ルールでどこまで説明できるか(359件中の正解数)

| ルール | 正解 | 入ると予測して待った | 待つと予測して入った |
|---|---|---|---|
| M5 だけ(60以下なら入る) | 317 | 14 | 28 |
| M1 だけ(55以下なら入る) | 293 | 15 | 51 |
| M5+M1(M5 55以下、または M5 60以下かつ M1 74以下) | 320 | 11 | 28 |

- M1 を足しても正解は 317 → 320 で、ほぼ増えない。M5 60〜75 で M1 が下がっていても、74%は待っている。

## 3. 結論

- **主は M5 RSI**。M5 が低ければ M1 に関係なく入り、M5 が高すぎれば M1 が下がっても入らない。
- **M1 RSI も効いている傾向はある**(M5 が中間の時、M1 が下がると入りやすい)。「両方を見ている」可能性はあるが、「M5 も M1 も X 以下なら入る」という単純なしきい値では説明できない。
- 毎分1回の記録なので、分の途中で M1 RSI がいくつの時に入ったかは分からない。M1 RSI は1分の中で大きく動くため、この解像度では M1 の条件は決められない。
- 決めるには、ナンピンの瞬間と待機中の M1・M5 の RSI(とストキャス)を記録する必要がある。v3.7 のイベント記録(ea_monitor_events_v37.csv)には RSI の列が無い。
