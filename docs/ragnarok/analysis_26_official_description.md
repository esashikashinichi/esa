# 解析26: 公式説明文と、これまでの解析の照合(09-25)

- Shinさんが Ragnarok の公式説明文を共有した。公開デモ口座で EA_Monitor を動かす予定。
- 公開口座の番号・パスワードはこのファイルには書かない(会話ログにのみ記録)。

## 1. 説明文の要点

- 5ロジック厳選エントリー、5ロジック個別 ON/OFF。
- 経済指標の前後で自動停止。指標情報は fxshihyo.com。★3 = ★3 の前後で停止、★2 = ★2〜3 の前後、★1 = ★1〜3 の前後。
- ナンピンフィルター(true/false): 「相場の過熱をオシレーターで検知。トレンド発生時にはむやみにナンピンせず、ある程度落ち着いたところでナンピンする」。フィルターを使うと利確に大きい戻しが必要になる、とも書かれている。
- 曜日ごとの稼働時間設定。マイクロ/セント口座対応。設置時間足は15分足。
- 推奨証拠金: マイクロ(セント)口座 10万円で 0.1〜(0.1 が最低ロット)。スタンダード口座 100万円で 0.01〜。
- 「想定週利100%」は販売側の主張で、検証していない。

## 3. 公開デモ口座で見られること

- 公式のデモ口座では a〜e の5ロジックが動く(Shinさん)。d・e のルールを初めて調べられる。
- 口座の履歴(全期間)が残っていれば、過去の全取引(コメント a_0〜e_n 付き)をまとめて取得でき、エントリーの発火条件とナンピン待機の標本を大きく増やせる。
- 注意: m1state の指標は確定足(shift 1)の値。EA がオシレーターを形成中の足(shift 0)で判定しているなら、待機の数値は確定足の記録では決められない(解析25の限界の理由の一つ)。
