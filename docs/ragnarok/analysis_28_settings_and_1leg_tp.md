# 解析28: 設定の確認と、1段の決済幅の本番・デモの違い(09-25)

## 1. Shinさんからの確認事項

- EA は通常口座・マイクロ口座で共通。ロットの既定値は 0.01。マイクロ口座は最低 0.1 ロットの縛りがある。
- **ロット以外の設定項目は無い**(本番とデモで違うのはロットと週末停止だけ)。
- **本番の 09-25(金)サーバー時間10:00以降のエントリーは、週末停止をオフにしていたため**。

## 2. これで確定したこと

- デモが金曜 10:00(サーバー時間。夏時間の日本時間16:00)で新規を止めたのは週末停止(`WeekEndStopTime=10:00`)。解析27の6節の見立てどおり。
- 本番の 10:34:01 の a・b・c の売り(−101,230円の損切り、解析23)は、週末停止がオンなら入らなかった取引。
- 口座の大きさの換算: 本番 GOLDmicro 0.1ロット(1ドルで約15.8円)、デモ GOLD 0.01ロット(1ドルで約158円)。デモの金額は本番の約10倍。

## 3. 1段の決済幅は、設定では説明できない

同じ時間帯(09-24 01:48〜09-25 10:00)で、本番とデモが**5秒以内に同じ方向で入った1段の束 141組**を比べた(約定価格どうしの幅、pts)。

| | 25% | 中央値 | 75% |
|---|---|---|---|
| 本番(GOLDmicro 0.1ロット) | 67 | **73** | 85 |
| デモ(GOLD 0.01ロット) | 102 | **109** | 120 |

- 同じ初弾でも、本番は約36pts(0.36ドル)早く決済している。中央値の比はほぼ 2:3。
- 2段以上の決済幅は本番・デモともに中央値 約140pts で同じ。
- 設定の違いはロットだけなので、1段の決済の判定は、ロット・銘柄(GOLDmicro と GOLD)・口座の種類によって変わる計算をしている可能性がある(例: 金額で判定している、など)。ただし、単純な「決済金額が一定」では本番・デモの数字が合わず、仕組みは未特定。
- v3.8 の決済の記録(最大含み益・100pts到達後の最小含み益)を本番とデモで並べると、決済の条件をさらに詰められる。
