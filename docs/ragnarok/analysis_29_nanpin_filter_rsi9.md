# Ragnarok 解析29: ナンピンフィルターの特定(公開デモ口座・EA_Monitor v3.8)

作成: 2026-09-30 / データ: 公開デモ口座(a〜e、GOLD 0.01ロット)、EA_Monitor v3.8 のログ
スクリプト: `tools/ragnarok/nanpin_filter_rsi9.py`

## 結論

- **ナンピンフィルター = M5 の RSI(期間9)、形成中の足(shift 0)、閾値 約65。**
  - 売りの束(逆行 = 上昇): M5 RSI(9) が 65 を超えている間はナンピンしない。
  - 買いの束(逆行 = 下落): M5 RSI(9) が 35 を下回っている間はナンピンしない。
  - 「420秒以上・約110pts以上の逆行」を満たした後、RSI が 65(35)の内側に戻った瞬間にナンピンする。
- **このフィルターは2回目以降のナンピン(束が2段以上)にだけ掛かる。1回目のナンピンには掛からない。**
- 公式の説明「ナンピンフィルター(オシレーターの過熱)」と一致。以前の推定「M5 RSI(14) が主」(解析25)は、RSI(14) が RSI(9) に近い動きをしていたため。

## 3. 1回目のナンピンと2回目以降の違い

M5 RSI(9)、閾値 65 で分けて見た。

| | ナンピン側(RSI ≤ 閾値) | 待機側(RSI > 閾値) |
|---|---|---|
| 2回目以降、閾値 64.5 | 0.709(158回) | 0.997(3,518行) |
| 2回目以降、閾値 65.0 | 0.943 | 0.996 |
| 2回目以降、閾値 65.5 | **0.994(157/158)** | **0.987** |
| 2回目以降、閾値 66.0 | 0.994 | 0.970 |

- 2回目以降で外れたナンピンは、RSI(9) が 65.0〜65.3 の9回と 66.7 の1回。65.0〜65.3 は作り直しの誤差(ティックの時刻差)の範囲。閾値は **65(買いは35)** が有力。
- **1回目のナンピン(94回)**: RSI(9) が 65 を超えたまま発注したのが 11回(最大 83.3)。待ち時間の中央値は1秒。待機の記録(10行)は全て条件成立の直後(逆行 111〜130pts)で、RSI とは無関係。→ **1回目のナンピンには RSI のフィルターが掛からない。** この待機は逆行幅の判定のわずかな差(約110pts の境目)とみられる。
- d・e で外れていたのは全て1回目のナンピン。2回目以降の d は 3/3 で一致。
