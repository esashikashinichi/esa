# Ragnarok 解析30: 利確の仕組みと、本番(マイクロ口座)・デモ(ノーマル口座)の違い

作成: 2026-09-30 / スクリプト: `tools/ragnarok/tp_threshold_real_vs_demo.py`

## 結論

- **利確は「含み益が発動ラインに届いたら追いかけ、少し戻った所で決済」する形**。決済幅そのものは発動ラインより上にも下にもなる。
- **発動ラインは本番とデモで違い、本番はデモのちょうど 2/3**:

| | 本番(マイクロ口座、GOLDmicro 0.1ロット) | デモ(ノーマル口座、GOLD 0.01ロット) |
|---|---|---|
| 1段の発動ライン | **67pts**(利益で決済した67束の最大含み益の最小が 67.0) | **100pts**(214束の最小が 100.0) |
| 2段以上の発動ライン | **約100pts**(23束の最小が 102.4) | **約150pts**(90束の最小が 151.0) |
| 1段: 発動後の戻り(中央値) | 7pts、最大含み益から約1秒で決済 | 6pts、約1秒 |
| 2段以上: 発動後の戻り(中央値) | 46pts、約4秒 | 41pts、約3秒 |

- 同じ時間帯(09-28)に限っても、1段の発動ラインは 本番 67.0(19束)/ デモ 101.0(27束)。**相場の違いではなく、口座(銘柄・ロット)の違い**。
- 解析28の「1段の決済幅 本番73pts・デモ109pts」の差はこれで説明できる(発動ライン 67 と 100 に、小さな戻りが加わった値)。
- 2段以上は、これまで「約140pts」としていたが、これは主にデモの値(発動150 − 戻り)。本番の発動ラインは約100pts で、戻りを差し引いた決済幅の中央値は 78.5pts。
- 以前「早期決済(100pts到達後に50〜70ptsまで戻ると決済)」としていたものは、本番の2段以上の「発動ライン約100pts + 戻り」の形だった。

## 2/3 の理由(未確定)

- 本番とデモで違うのは、口座の種類(マイクロ/ノーマル)、銘柄(GOLDmicro/GOLD)、ロット(0.1/0.01)だけ(Shinさん確認: EA の設定はロット以外に無い)。
- EA が発動ラインを pts ではなく、銘柄の仕様(契約サイズ・ティック価値など)やロットから計算している可能性が高い。どの値から 2/3 になるかは、今のデータでは決められない。
- マイクロ口座のデモは存在しないため、同じ口座の種類で比べる検証はできない。

## 今後への影響

- バックテストでは、利確を「発動ライン(本番: 1段67・2段以上100、デモ: 100・150)+ 戻りで決済」に直す必要がある。
- 本番のほうが利確が浅いため、1束あたりの利益はデモの約2/3。ナンピンの条件は同じなので、同じ逆行でも本番のほうが利確に必要な戻りは小さい。
