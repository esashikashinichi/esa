# Ragnarok 解析33: b 型 + 3段目からのヘッジ(同ロットの反対売買)

作成: 2026-10-01 / スクリプト: `tools/ragnarok/hedge_from_leg3.py`
Shinさんの構想: b がナンピンした時(3段目から)に同じロットの反対ポジションを持つ。反対ポジションは「プラスになったら切る」、買いの束(元の束)はロジックに任せる。

> **【訂正 2026-10-01】この解析の数字は誤り。** バックテストのロットの丸めに誤りがあり(0.01 × 1.5 を 0.01 に丸め続けたため、ナンピンしてもロットが 0.01 のまま増えなかった)、期間の終わりに残った束の含み損も損益に入れていなかった。正しい数字と結論は **解析34**(`analysis_34_plus_search.md` の 0節)を見ること。「最大12段+ロックで +957円・損切り0回」は取り消し(直すと −24,663円・損切り4回)。「プラスで切るヘッジは効果がほぼ無い」という結論は変わらない。以下は誤りを含む元の内容(消さずに残す)。

## 結論

- **「プラスになったら切る」形のヘッジは、最大含み損をほぼ減らさなかった**(ヘッジ無しと同じ −30,532円)。損益の差も ±1,000円程度で、効果はほぼ無い。
  - ヘッジが利益で切れた後もトレンドが続き、最悪の含み損はヘッジが無い時に来るため。
- **ヘッジを切らずに、束の利確まで持ち続ける形(ロック)は、最大含み損を大きく減らした**。ただし利益もほぼ消える。
  - 最大40段: 最大含み損 −30,532円 → −7,569円。損益 +13,220円 → −143円。
  - **最大12段 + ロック: 最大含み損 −3,636円、損益 +957円。許容損失(−5,000円)の損切りは0回**。調べた中で唯一、許容の中に収まった。
- ヘッジ無しで −5,000円の損切りを入れると、75日で6回損切りし、損益は −7,602円。
- 今の結論: **ヘッジは「利益を増やす道具」ではなく、「最大含み損を小さくする代わりに利益を削る道具」**。使うなら「ロック」と「段数の上限」の組み合わせ。

## 読み方

- 「プラスで切る」ヘッジ(trail・rsi・rebound)は、ヘッジだけの損益が −1,700〜+900円で、ほぼ0。**上げ下げの繰り返しで、利益で切れる分と、束の利確で損のまま決済される分がほぼ相殺される**。
- ロック(hold)は、3段目以降のロットが売りと買いで打ち消し合うので、実際に動くのは1〜2段目の分だけ。最大含み損は小さくなるが、束が利確する時にヘッジの損を払うので、利益も消える。
- 最大段数12とロックを組み合わせると、束の利確が早く来る(段数が少ない)ため、ヘッジの損が小さくて済み、わずかにプラスが残った。

## 注意(このテストの限界)

- 初弾は条件がそろった足で毎回入る(1日約36束)。ラグナロクの b はこの約3割しか入らない(解析31・32)。
- M1 足の終値でナンピンを判定し、利確は発動した足で「一番良い値 − 戻り」で決済しているため、利確はやや甘い。全ての行で同じ条件なので、比較には使える。
- 75日間だけ。スワップ(持ち越しの金利)は入れていない。XM で両建てした時の証拠金の扱いは未確認。
- 最大段数12の束は、12段目以降もナンピンせずに利確を待つ(損切りは −5,000円の設定だけ)。
