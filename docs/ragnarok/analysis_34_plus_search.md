# Ragnarok 解析34: 自作 b 型 EA をプラスにする方法の探索(解析33の訂正を含む)

作成: 2026-10-01 / スクリプト: `tools/ragnarok/hedge_model_v2.py`(モデル)、`tools/ragnarok/plus_search.py`(比較・探索・5期間検証)
Shinさんの依頼: (1) ロックを始める段を変えて試す。(2) プラスに持っていく最善の方法をあらゆる角度から探す。

## 0. 解析33の訂正(重要)

解析33のバックテストには2つの誤りがあった。**解析33の数字は使わないこと**。

| 誤り | 内容 | 直した後 |
|---|---|---|
| ロットの丸め | 前の段のロットを 0.01 単位に丸めてから ×1.5 していたため、0.01 × 1.5 = 0.015 → 0.01 に戻り、**ナンピンしてもロットがずっと 0.01 のまま**だった | 丸める前の値に掛け続け、各段で四捨五入。デモの実測(0.01, 0.02, 0.02, 0.03, 0.05, 0.08, 0.11, 0.17, 0.26, 0.38, 0.46, 0.55, 0.66, 0.80, 0.96)と一致 |
| 期間の終わり | 期間の終わりにまだ決済されていない束の含み損を、損益に入れていなかった | 最後の終値で決済したものとして損益に入れる |

直した後の解析33の主な行(75日、−5,000円の損切りあり):

| 形 | 損益 | 最大含み損 | 損切り回数 |
|---|---|---|---|
| ヘッジ無し・最大40段(ラグナロク b 型) | +12,998円 | −9,923円 | **11回** |
| プラスで切るヘッジ(9通り) | −18,487〜+477円 | −9,923円前後 | 11回 |
| ロック・最大40段 | −50,824円 | −6,638円 | 8回 |
| ロック・最大12段 | −24,663円 | −7,151円 | 4回 |

- 解析33の「最大12段+ロックで +957円・損切り0回」は**取り消し**。直すと −24,663円・損切り4回。
- 「プラスで切るヘッジは効果がほぼ無い」という結論は変わらない(むしろ悪化する)。
- ラグナロク b 型(0.01 から)は、−5,000円(資金1万円の50%)の損切りが75日で11回(最初は 07-21)。**資金1万円なら数日で許容損失に届く**。損益が +12,998円になるのは、損切りの後も資金が補充される前提の計算。

最大含み損が −5,000円を超えているのは、1分足の中で一気に動いた分(足の終値で損切りを判定しているため)。

## 1. ロックを始める段の比較(依頼1)

- **どの段から始めても、ロックはマイナス**。始める段を遅くするほど損は減るが、プラスにはならない。
- ロックは損切り回数を減らす(11回 → 1〜2回)が、束が利確する時にヘッジの損を払い続けるため、利益が残らない。

## 2. プラスにする方法の探索(依頼2)

### 方法
- ランダムに選んだ設定 1,600通りを、前半(07-17〜08-26)と後半(08-27〜09-30)に分けて計算。両方プラスの設定を探した。
- 変えた項目:
  - ヘッジ: 無し / ロック(2段目または3段目から)
  - 最大段数: 3・4・5・6・8・12
  - ロット倍率: ×1.0(全段同じロット)/ ×1.5
  - ナンピン幅: 1.1・2.0・4.0ドル
  - **束を持つ時間の上限**: 無し・6時間・24時間・72時間(超えたら決済)
  - 束ごとの損切り: 無し・1,000円・2,000円
  - 上位足のトレンド: 無し / H1 の MA20 の向きに逆らう新規を止める
  - 初弾の K − D の下限: 0・10
  - 利確の発動ライン: 本番どおり / 1.5倍
  - 日足の始値から逆方向に20ドル以上動いた日は新規を止める: 無し / あり
- 全ての設定に、口座全体の −5,000円の損切りを入れた。

### 結果の全体像
- **両方の期間でプラスになったのは 1,600通り中126通り(8%)**。どの項目も、損益の中央値はマイナス。
- **一番効いた項目は「束を持つ時間の上限 6時間」**。両方プラスの割合は 6時間 12%、72時間 9%、上限無し 7%、24時間 3%。
- 日足の始値から逆方向に20ドル動いた日の新規停止も効いた(あり 10%、無し 6%)。上位足のトレンドで止めると悪化した(H1 3%、無し 13%)。
- 次に効いたのは、最大段数を少なくする(3段)、ナンピン幅を広くする(4ドル)、ロット倍率 ×1.0(ナンピンしてもロットを増やさない)。
- ヘッジ(ロック)は最大含み損を半分程度に減らすが、損益は増えない。

- **一番良かった設定: 75日で +4,089円(資金1万円に対して約+41%)、最大含み損 −1,084円、損切り0回**。5期間中4期間がプラス。
- 上位の設定は全て「6時間で決済」と「段数3〜4」。**ラグナロクの「ナンピンで粘って利確を待つ」とは逆の、「少なく持って早めに切る」形**。
- 最初の15日(07-17〜07-31、07-21・07-23 のトレンド日を含む)は、上位の設定でも全てマイナス。

## 3. 結論

- **プラスに持っていく一番の方法は「段数を少なくし(3〜4段)、束を6時間以上持たない」こと**。ヘッジ(反対売買)は、プラスで切る形もロックも、利益を増やさない。
- ラグナロク b 型のまま 0.01 にすると、許容損失(−5,000円)に75日で11回届く。資金1万円では使えない。
- 一番良い設定でも、**1,600通りの中から選んだ結果**なので、実際より良く見えている可能性が高い。5期間のうち4期間はプラスだったが、トレンド日を含む期間はマイナス。

## 4. 注意(このテストの限界)

- 75日分の1分足だけ。トレンドの強さが違う時期(2025年など)は確かめていない。
- 初弾は条件がそろった足で毎回入る(ラグナロクの約3倍)。1分足の中の値動きは見えないので、利確・損切りの値は近似。
- スワップ、スリッページ、XM で両建てした時の証拠金は入れていない。
- 時間の上限6時間は、実質的には「時間で切る損切り」。損を確定する回数が多いので、スプレッドの影響を強く受ける。
