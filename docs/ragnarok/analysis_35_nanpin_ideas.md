# Ragnarok 解析35: ナンピン EA で勝つための案の検証(A1〜A6・B1〜B5・C1〜C3)

作成: 2026-10-01 / スクリプト: `tools/ragnarok/ideas_model.py`(モデル)、`ideas_run.py`(案ごとの比較)、`ideas_a2.py`(A2 の周辺・固定時間との比較・組み合わせ)、`ideas_b2c2.py`(B2・C2)
Shinさんの依頼: 「ナンピン EA で勝つために、一般的なもの以外を、あらゆる視点から」→ 案を出した後、「検証して」。

## 結論

- **効いたのは A2(戻りの半減期で、束を持つ時間の上限を決める)だけ**。2つの基準の両方で、損益・損切り回数・期間ごとの安定が良くなった。
  - ラグナロク b 型(0.01 から・最大40段): **+12,998円・損切り11回 → +19,127円・損切り2回、5期間すべてプラス**、最大含み損 −9,923 → −5,619円。周りの設定15通りのうち14通りがプラス、10通りが5期間すべてプラス。
  - 解析34の一番良い設定(最大3段・6時間): +4,089円 → +5,145円、5期間すべてプラス。ただしこちらは **固定3時間(+5,398円)とほぼ同じ**で、「半減期」の効果ではなく「6時間より短く切る」効果。
  - ラグナロク b 型は、**固定時間(1〜6時間)で切ると悪くなる**(−8,253〜+6,383円)。半減期で相場ごとに時間を変えると良くなる → b 型では「相場に合わせて時間を変える」ことに意味がある。
- **効かなかった、または悪くなった案**: A1 分散比、A3 ATR、A4 売りの制限、A5 ナンピンを止める時間帯、A6 ロールオーバー、B3 段数で逆向き、B5 ロット固定・幅拡大、B4 ペア決済(b 型では大きく悪化)。
- **わずかに効いた案**: B1 切ったら逆向き(+86〜+143円)、B4 ペア決済(最大3段型だけ +339円)、B2 ブレイクアウトとの組み合わせ(+300〜+900円、最大含み損はほぼ同じ)。
- **C(口座の仕組み)**: ラグナロク b 型を損切り無しで 0.01 にすると、**07-21(開始から4日目)に資金1万円がゼロになる**(ゼロカット)。出金で守れるのは、その前に出金できた分だけで、今回は0円。

(S は全ての行で −5,000円の損切り0回。最大含み損は −656〜−1,312円)

読み方:
- A1(分散比)は、トレンドの判定としては働かなかった。15分と1分の値動きの比は、1分足の細かい動きに左右されやすく、数時間続くトレンドを見分けられていない。
- A4: この75日は、買いの束も売りの束も損益はほぼ同じ(R: 買い +34,372円、売り +33,847円)。長期の上昇の偏りは、数時間の束には効いていない。
- A5: ナンピンを止めると、その間に逆行がさらに進んでから入るため、b 型では損切りが増えた。
- B3: 3段に達した時点で逆向きに入ると、その後に戻ることが多く、逆向きの建玉の損が増えた(S で −1,018〜−1,697円)。
- B4: b 型では、ペア決済で段数が減ると、次のナンピンでまた積み上がり、損切りが増えた。
- A6: スプレッドの広がりはモデルに入っていない(一定 0.55ドル)ので、この結果は「時間を避けた影響」だけ。v3.9 のティック記録でスプレッドを確かめるまで、判断できない。

## 結果2: A2 は「半減期」の効果か、「短く切る」効果か

| | S(最大3段) | R(ラグナロク b 型) |
|---|---|---|
| 固定1時間 | +4,447(5/5、最大含み損 −341) | +236(4/5、損切り0) |
| 固定2時間 | +4,836(4/5) | +595(2/5) |
| 固定3時間 | **+5,398**(4/5、−597) | −8,253(2/5、損切り2) |
| 固定4時間 | +4,744(4/5) | −2,516(3/5、損切り7) |
| 固定6時間 | +4,089(4/5) | +6,383(2/5、損切り11) |
| **A2 周辺15通り**(半減期 × 0.5〜1.5、直近16〜32時間の M5) | +4,427〜+6,574(5/5 が11通り) | +4,847〜+25,365(5/5 が10通り、損切り1〜5) |

- S では、固定3時間と A2 はほぼ同じ。S の改善は「6時間は長すぎた」ことによる。
- R では、固定時間はどれも基準以下か、損切りが多い。A2 は15通り中14通りが基準を上回るか近く、損切りも1〜5回に減った。**段数が多いナンピンほど、「相場に合わせて切る時間を変える」ことが効く**。
- 半減期の中央値: 直近1日の M5 で 3.2時間、2日で 6.9時間。解析34で選ばれた「6時間」は、2日で測った半減期の中央値とほぼ同じ長さだった。
- 上限・下限(0.5〜2時間、12〜48時間)を変えても、結果はほぼ同じ。

## 結果3: B2(ブレイクアウトの EA との組み合わせ)

M15 のドンチャン・ブレイクアウト(直前 N 本の高値・安値を抜けたら入る、M 本の逆側を抜けたら決済)を、0.01 ロットで同じ75日に動かした。

| ブレイクアウト | 単独の損益 | 取引数 | S との日ごとの損益の相関 | S + ブレイクアウト(0.01) | 最大の落ち込み |
|---|---|---|---|---|---|
| 20本 / 10本 | −451 | 227 | **−0.40** | +3,623 | −1,196 → −1,299 |
| 55本 / 20本 | +297 | 92 | −0.17 | +4,370 | −1,196 → −1,193 |
| 96本 / 48本 | +268 | 43 | 0.00 | +4,342 | −1,196 → −1,196 |

- 速いブレイクアウト(20/10)は、S と逆の動き(相関 −0.40)をするが、単独で負けるので足すと悪くなる。
- 遅いブレイクアウトは単独でわずかにプラスで、足すと損益が少し増え、落ち込みは同じ。効果は小さい。

## 結果4: C(口座の仕組み)

| 確認 | 結果 |
|---|---|
| C1 ゼロカット | R(ラグナロク b 型、0.01)を損切り無しで動かすと、**07-21 08:25(開始から4日目)に資金1万円がゼロ**。資金が無限なら75日で +127,326円だが、途中の最大含み損は −473,311円。最大12段でも 07-21 にゼロ。ゼロカットで損は1万円で止まるが、口座は4日で終わる |
| C2 出金(1日の終わりに1.5万円以上なら、1万円を残して出金) | R 損切り無し: ゼロになる前に出金できた額は0円。−5,000円の損切りありの R・S は75日で口座がゼロにならず、出金しても総額は同じ(R: 出金 11,375円 + 口座 11,598円) |
| XM の規約(確認した範囲) | **複数の口座の間・他社との間の両建ては禁止**(違反すると出金拒否・利益の取り消し)。同じ口座の中の両建ては可。**出金すると、出金した割合と同じ割合のクレジット(ボーナス)が消える**。**ゼロカットが起きるとボーナスは全て消える** |

- C1・C3 は、相場のデータでは検証できない(規約・口座の扱いの話)。
- 「口座を分けて反対向きに持つ」はしてはいけない。同じ向きで口座を分けることの扱いは、XM のサポートに確認が必要(未確認)。
- 出金はボーナスを減らすので、ボーナスを含み損の余裕として使っている間は、出金と余裕がトレードオフになる。

## 注意(このテストの限界)

- 75日分の1分足だけ。A2 の周りの設定がそろって良いことは確かめたが、**使っていない期間での確認(M5 足 04-13〜07-16)はまだ**。
- 案は全部で約100通り試した。その中で良いものを選んでいるので、実際より良く見えている可能性がある。A2 は2つの基準と周りの設定でそろって効いたので、偶然の可能性は他の案より低い。
- R + A2 でも、−5,000円の損切りが75日で2回あった。資金1万円で R 型を動かすのは、まだ危険。
- スプレッドの広がり・スリッページ・スワップは入れていない。

## 次に確かめること

1. A2 を、使っていない期間(M5 足 04-13〜07-16)で確かめる。M5 足用にモデルを直す必要がある。
2. A2 の半減期を、EA の中で計算できる形にする(直近288本の M5 終値で、値動きと1本前の値段の回帰。計算は軽い)。
3. 自作 EA の候補は「S 型 + 時間の上限を半減期で決める(または固定3時間)」。作る前に仕様を確認する(ルール1)。
