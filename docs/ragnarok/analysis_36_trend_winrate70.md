# Ragnarok 解析36: トレンドフォローで勝率70%以上になる方法(時間決済なし)

作成: 2026-10-01 / スクリプト: `tools/ragnarok/tf_model.py`(モデル)、`tf_search.py`(第1段 3,015通り)、`tf_search2.py`(第2段 3,348通り)、`tf_robust.py`(代表の頑健さ)、`tf_m1check.py`(M1 での答え合わせ)
Shinさんの依頼: 「時間決済は運だと思うのでだめ。トレンドフォローのロジックで70%以上の勝率になる方法を徹底的に調べて」。

## 結論

- **勝率70%以上は作れる。鍵は入口ではなく出口の形**: 「建玉の一部(30%)を小さい利確(0.5〜1 ATR)で先に決済し、残り(70%)は損切りを建値に動かしてトレンドを追いかける(4 ATR の追いかけ)。最初の損切りは広く(4〜5 ATR)」。
  - 最初の利確に届いた取引は、残りが建値で切られても必ずプラスで終わる → 勝率は「最初の利確に届く確率」になる(80〜90%)。
  - 残りの70%がトレンドを取るので、勝率を上げても利益が消えない。
  - 時間決済は使っていない。決済は利確・損切り・追いかけの値段だけ。
- **一番安定していたのは C「EMA20 への押し目 + H1・H4 のトレンド方向」**:
  - 2.2年で 1,047回、**勝率83.0%、PF 1.29**。半年ごとの5期間すべてで勝率80〜86.5%・すべて黒字(PF 1.08〜1.69)。
  - 設定を1つずつ変えても勝率78.7〜87.8%・PF 1.16〜1.34。スプレッド2倍でも PF 1.19。M1 で答え合わせしても PF 1.26 → 1.22。
- **注意: 勝率が高い代わりに、1回の負けが大きい**。平均の勝ち 7.8ドル、平均の負け 29.4ドル(負け1回 ≒ 勝ち3.8回)。最大連敗は3回。
- 0.01 ロットでは年 約1,100円(最大の落ち込み −541円)。資金1万円・許容損失 −5,000円なら、0.03〜0.05 ロットで年 約3,300〜5,500円(最大の落ち込み −1,600〜−2,700円)。

| 分かったこと | 数字 |

| 本来のトレンドフォロー(反対シグナル・追いかけ)は勝率が低い | 勝率12〜40%、PF 1.3〜1.7(前後とも) |
| 利確を小さく・損切りを大きくすると勝率は上がるが、利益が薄い | 55本ブレイク + H4、利確0.75・損切り4 ATR: 勝率84〜85%、PF 1.04 / 1.19 |

## 第2段: 部分決済を加えた比較(3,348通り)

入口9種(40・55・80・100本ブレイク、EMA20 押し目、RSI2、EMA クロス、ADX、MACD)× フィルター4種 × 出口93通り(固定12、部分決済81: 最初の利確 0.5/0.75/1.0 ATR、損切り 3/4/5 ATR、追いかけ 2/3/4 ATR、先に決済する割合 30/50/70%)。

- **前期間・後期間とも勝率70%以上・PF>1 は 1,081通り(32%)。そのうち 1,023通りが部分決済**。固定の利確・損切りは58通りだけ。
- 良い設定に共通: 先に決済する割合は30%、追いかけは4 ATR、損切りは3〜5 ATR。

## 注意(このテストの限界)

- M15 足のデータで計算した。M1 で確かめたのは最後の2か月だけ(ずれは小さかった)。
- 6,000通り以上を比べた中から選んでいる。C は5期間・周辺の設定・スプレッド2倍・M1 でそろって成り立ったので偶然の可能性は低いが、利益の厚み(PF 1.2〜1.3)は大きくない。
- 1回の負けが大きい(平均で勝ち約4回分)。窓開け(週末)では損切りより大きく負けることがある(最大 −187ドル)。週末をまたがない運用も検討の余地あり。
- スワップ・スリッページは入れていない。
- EA のファイルは作っていない(作る前に仕様を確認する、ルール1)。
