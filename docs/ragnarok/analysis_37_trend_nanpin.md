# Ragnarok 解析37: トレンドフォロー + ナンピン(押し目の買い増し)/ピラミッディング(順行の買い増し)で PF を上げる

作成: 2026-10-01 / スクリプト: `tools/ragnarok/tf_basket.py`(モデル)、`tf_basket_search.py`(5,760通り)、`tf_basket_robust.py`(頑健さ・M1 での答え合わせ)
Shinさんの依頼: 「今後、保存の前に必ず答えを提示すること。トレンドナンピンと組み合わせて PF がもっと高くなるのを探して」。
解釈: 解析36のトレンドフォロー(入口 + 部分決済)に、(a) 逆行したら買い増し(押し目ナンピン)、(b) 順行したら買い増し(ピラミッディング)を足した形。時間決済は使わない。

## 結論

- **押し目ナンピンで PF は上がる。ただし1回の負けが大きくなる**。M1 足でも成り立った候補は2つ。

| | 基準(ナンピン無し) | **N1: EMA20 押し目 + H1・H4 + ナンピン** | **N2: RSI2 押し目 + H4 + ADX + ナンピン** |
|---|---|---|---|
| PF(2.2年) | 1.28 | **1.70** | **2.38**(基準 1.87) |
| 勝率 | 83.0% | 94.2% | 98.8% |
| 5期間の PF | 1.08〜1.68 | 1.15 / 1.17 / 3.27 / 1.93 / 1.38 | 2.36 / 1.09 / 5.45 / 4.71 / 2.15 |
| M1 足での答え合わせ(07-18〜) | PF 1.25 | **PF 1.36**(M15 計算 1.97) | **PF 2.22**(M15 計算も 2.22) |
| スプレッド2倍 | 1.18 | 1.50 | 2.20 |
| 設定を1つずつ変えた時の PF の最小 | 1.18 | 1.31 | 1.36 |
| 0.01ロットの年の損益 | 約1,086円 | 約2,691円 | 約3,494円 |
| 最大の落ち込み | −541円 | −856円 | −1,690円 |
| 1回の最大損 | −295円 | −363円 | −759円 |
| 最大ロット(0.01 基準) | 0.01 | 0.05 | 0.08 |

- N2 は PF が最も高いが、平均の勝ち 8.5ドル・平均の負け 289ドル(負け1回 ≒ 勝ち34回分)。2.2年で負けは約12回。設定を変えると最大の落ち込みが −4,912円(0.01ロット)まで悪化した。
- **不採用**:
  - P1(RSI2 + ピラミッディング): M15 では PF 2.52、5期間 PF 1.62〜5.64 だったが、**M1 では PF 1.04**(M15 計算 1.50)。同じ足の中の順番に依存した見かけの利益。
  - P2(EMA20 + ピラミッディング): スプレッド2倍で PF 0.89 と赤字。

## 条件

| 項目 | 値 |
|---|---|
| データ | GOLDmicro M15 足 2024-07-23〜2026-09-21(2.16年)。M1 足 2026-07-18〜09-21 で答え合わせ |
| 前期間 / 後期間 | 2024-07〜2025-12 / 2026-01〜09 |
| 入口 | 解析36 の C(EMA20 押し目 + H1・H4)、B(RSI2 押し目 + H4 + ADX>20)、100本ブレイク |
| 方式 | 'nan'(逆行 step×ATR ごとに買い増し)、'pyr'(順行 step×ATR ごとに買い増し。買い増すたびに損切りを平均建値へ) |
| 買い増し | step 0.5〜2 ATR、最大 2〜5 段、ロット ×1.0 / ×1.5 |
| 損切り | 最初の建値から 4〜8 ATR(束全体で一括) |
| 利確 | 平均建値から 0.5〜1 ATR で 30%/50% を先に決済し、残りは損切りを平均建値に動かして 4 ATR で追いかけ |
| 同じ足の中 | 逆行を先に処理。窓開けは始値で決済。**買い増しした足では、足の中の順番が分からないので利確は次の足から** |
| スプレッド | 価格の 0.0128%(今の 0.55ドル)。2倍でも確認 |

## 経過(訂正を含む)

1. 最初の計算では、同じ足で買い増しと利確が両方起きた時に利確を認めていた。この仮定は甘く、勝率99%・PF 4〜5 という出来すぎた値になった。
2. 「買い増しした足では利確を次の足から」に直して計算し直すと、押し目ナンピンの PF は 1.7〜2.0 に下がった(落ち込みも −2,000〜−2,900円と大きい)。
3. 上位を M1 足(足の中の順番)・5期間・周辺の設定・スプレッド2倍で確認した。

## 注意(このテストの限界)

- 約5,760通りの中から選んでいる。N1 は M1・スプレッド・5期間でそろって成り立ったが、N2 は期間によって PF 1.09 の期間がある。
- ナンピンは「負けが少なく、まれに大きく負ける」形。2.2年に起きていない相場(窓開けの大きな逆行など)での最大損は分からない。
- M1 で確かめたのは最後の2か月だけ。
- スワップ・スリッページ・窓開けは入れていない。
- 資金1万円・許容損失 −5,000円なら、N1 は 0.03 ロットまで、N2 は 0.02 ロットまでが目安。
- EA のファイルは作っていない(作る前に仕様を確認する、ルール1)。
