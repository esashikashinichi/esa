# Ragnarok 解析38: 損切り無しの検証と、損切り幅の最適(トレンドフォロー + ナンピン/ピラミッディング)

作成: 2026-10-01 / スクリプト: `tools/ragnarok/tf_nosl.py`(損切り無しの計算)、`tf_sl.py`(損切り幅を変えられる計算)、`tf_sl_search.py`(2.4万通り)、`tf_sl_refine.py`(上位の周辺)、`tf_sl_robust.py`(頑健さ)、`tf_m5.py`(M5 足での答え合わせ)
Shinさんの依頼: 「損切を入れないで考えて」「1日のエントリー数も教えて」「ナンピン・ピラミッディング有りで、初めからもう一度検証して」「もっと確実な組み合わせを、あらゆる角度から」→ 損切り無しが赤字だったので「損切の数字を変えて最適解を探して。M1 足はあまり信用できない(M5 でも良い)」。

## 結論

- **損切りを無しにすると赤字**(0.01ロット、M15 足2.2年): 1段 −1,833円(期末に負けの建玉が2つ残る)、ナンピン2段 −16,872円(最大の落ち込み −19,303円)。損切り無しでは勝率がほぼ100%に見えるが、負けた束が決済されずに残るだけ。評価は含み損込みの資金曲線で行う。
- **最適は「RSI2 の押し目 + H4 + ADX + ピラミッディング2段、損切り 4.5〜5 ATR」**(M15)。損切り幅は 3〜12 ATR のどこでも PF 1.8〜2.3 で崩れない。

## 条件

| 項目 | 値 |
|---|---|
| データ | GOLDmicro M15 足 2024-07-23〜2026-09-21(2.16年、559日)。M5 足 2026-04-13〜09-21(116日)で答え合わせ。**M1 足は使わない**(Shinさん指示) |
| 前期間 / 後期間 | 2024-07〜2025-12 / 2026-01〜09 |
| 持ち方 | 1つの方向に1つの束。買いと売りを同時に持てる |
| 損切り | 最初の建値から sl×ATR(束全体で一括)。窓開けは始値で決済。slip×ATR だけ不利な値で決済。sl=inf は損切り無し |
| ナンピン | 逆行が nstep×ATR 進むごとに買い増し(最大 nl 回、ロット nmult^k) |
| ピラミッディング | 順行が pstep×ATR 進むごとに買い増し(最大 pl 回、ロット pmult^k) |
| 利確 | 平均建値から tp×ATR で frac を先に決済(frac=1 なら全決済)。残りは損切りを平均建値+スプレッドに動かし、高値から trail×ATR で追いかける |

| スプレッド | 価格の 0.0128%(今の 0.55ドル)。2倍・3倍でも確認 |
| 資金曲線 | 足ごとに「確定済み + 含み損益」(逆行側の値で評価)。最大の落ち込みはその山から谷まで |
| エントリー数 | 束の最初の1回(買い増しは数えない)を、データのある日数で割った値 |

## 探索

1. **損切り無し**(入口10種 × フィルター4種 × 買い増しの形25 × 利確の形25 の探索は途中で止め、代表で確認): 上の通り赤字。
2. **損切り幅の探索 24,192通り**: 入口8種(押し目 EMA20・RSI14、RSI2、ブレイク55・100、EMA クロス、MACD、ADX)× フィルター4種 × 買い増しの形9 × 利確の形12 × 損切り7(2・3・4・5・6・8・12 ATR)。
3. **損切り幅別の傾向**: 損切りを広げると勝率は上がる(2 ATR で 66% → 12 ATR で 94%)が、最大の落ち込みの中央値も増える(1,332円 → 3,150円)。前後ともプラスの設定が多いのは 3〜4 ATR(32%・31%)。
4. **前後プラス・5期間プラス・勝率70%以上・取引数300以上は 1,239通り**。損益 ÷ 最大の落ち込みの上位は、ほぼ「RSI2 + H4 + ADX + ピラミッディング」。

## 注意(このテストの限界)

- 約2.4万通りから選んだ結果。M5 で確かめたのは約5か月分だけで、M5 では PF が M15 より下がった(1.36)。
- 最大の落ち込みは過去2.2年の値。今後はこれより悪くなる可能性が高い(安全側にロットを半分程度に)。高値更新が止まった最長は124営業日、2025年後半は PF 1.16 とほぼ横ばいだった。
- 利確幅 0.6 ATR 以上、ピラミッディングの幅 1.0 ATR 以外では成績が落ちる。数値の少しの違いに敏感なので、EA にする場合も値を変えない。
- 窓開け・スワップは未反映。損切りのずれは最大 0.6 ATR まで確認したが、週末をまたぐ大きなずれは確認していない。
- EA のファイルは作っていない(作る前に仕様を確認する、ルール1)。
