# Ragnarok 解析39: RSI をボリンジャーバンドで見る入口、ナンピン・ピラミッディングとの組み合わせ、上位足の高安の損切り、M5 での答え合わせ

作成: 2026-10-01 / スクリプト: `tools/ragnarok/tf_rsibb.py`(入口の総当たり)、`tf_rsibb_np.py`(ナンピン・ピラミッディング)、`tf_sl2.py`(損切り位置を入口ごとに渡せるエンジン)、`tf_swing.py`(上位足の高安の損切り)、`tf_swing_m5.py`(M5 足での答え合わせ)
Shinさんの依頼(順に): 「RSI をボリンジャーバンドで見た場合どうですか」→「それにナンピンとピラミッディングを組み合わせると」→「損切を上位足の直近高安にした場合どうですか」→「M5 でも検証して下さい」。

## 結論

- **RSI×ボリンジャー、ナンピンの追加、上位足の高安の損切りは、M5 の答え合わせで崩れたため取り下げ**。総合で一番残るのは、解析38の **R(RSI2 < 10 + H4 + ADX + ピラミッディング2段、固定損切り 5 ATR)**(M5 PF 1.36)。
- M5 は全ての候補で、M15 の同期間より PF が下がった。スプレッド2倍では R(利確 0.5)でも PF 1.02、他はほぼ全部1未満。
- M15 で見えた「`recross` RSI2 の PF 2.53・落ち込み −269円」は過去最適化の見かけで、M5 では PF 0.97。

## 第1段: RSI×ボリンジャー単体(486通り × 6設定)

型別(取引100回以上):

| 型 | PF 中央値 | 前期・後期とも PF > 1 | 5期間すべてプラス |
|---|---|---|---|
| `brk` | 1.30 | 60% | 15通り |
| `recross` | 1.09 | 43% | 6通り |
| `rev` | 1.18 | 76% | 27通り |

- 取引300回以上・勝率70%以上・前期後期とも PF > 1・5期間すべてプラスは47通り。
- 一番良い形(M15): `recross` RSI2・バンド2σ・フィルター無し・ピラミッディング2段・利確 0.3 ATR・損切り 5 ATR → 453回(1日 0.81回)、勝率 93.4%、PF 2.53、損益 +2,016円、最大の落ち込み −269円、1回の最大損 −112円、5期間すべてプラス。
- 他の上位は `brk`(上限ブレイク、PF 1.6〜1.7)。R(PF 2.00、損益 +5,331円、落ち込み −448円)は損益では上回られない。

## 第2段: ナンピン + ピラミッディング(2,106通り)

- 入口 13種(第1段の上位12 + R)× ナンピン9形(なし、2段/3段 × 幅 1/2 ATR × ロット ×1.0/×1.5)× ピラミッディング 0/2/3段 × 利確 0.3/0.5 × 損切り 5/8/12 ATR。
- 形別(取引300回以上): 買い増し無し PF 1.56・落ち込み 485円 / ピラミッディングのみ 1.53・734円 / ナンピンのみ 1.35・1,624円 / ナンピン+ピラミッディング 1.44・1,650円。**ナンピンは PF の中央値を下げ、落ち込みを約3倍にする**。
- 見かけの1位(PF 6.70、勝率 99.7%、336回中の負け約1回で −645円)は統計として意味が無い(損切りが遠い形の典型。解析37の出来すぎと同じ型)。
- 利益を増やす形: `recross` RSI14・1.5σ + ナンピン2段(×1.5、幅 1 ATR)+ ピラミッディング3段・利確 0.3・損切り 5 → 1,766回(1日 3.16回)、勝率 97.1%、PF 2.12、+8,994円、落ち込み −1,065円、最大損 −444円。損益 ÷ 落ち込みは 8.4 で、R の 11.9 に届かない。
- 損益 ÷ 落ち込みの上位12のうち11個が R の派生(RSI2 < 10 固定しきい値)。

## 第3段: 損切りを上位足(H1/H4)の直近高安にする(402通り)

- 損切り = 確定した上位足の直近 n 本の最安値(売りは最高値)∓ buf × ATR。距離を ATR 倍に換算(下限 1.0)。cap 超は上限に切り詰め(clip)か見送り(skip)。H1 は n = 3/5/10/20、H4 は n = 2/3/5/10、buf = 0/0.3、cap = 6/12 ATR。
- 中央値では固定 5 ATR のほうが良い(R の PF 2.00 に対し H4 高安 1.83、H1 高安 1.47)。H4 は H1 より良く、H1 は近すぎてノイズで切られる。
- clip で固定を上回ったのは、ナンピンを含む形の落ち込み(−1,065 → −854円、H4 直近5本・cap 6)と、R の H4 直近10本・cap 12(PF 2.20 → 2.21、損益はほぼ同じ)。ただし1回の最大損は増える(−444 → −560円)。
- skip(高安が遠い取引を見送る)は PF 3.7〜7.0 だが取引は 218〜259回(1日 0.4回)。例: `recross` RSI2・H1 直近10本・cap 6・skip → PF 4.29、損益 +1,839円、落ち込み −224円。
- 注意: 「固定 ATR」の比較行はコードの仕様で全て 5 ATR になっていた(3/8 ATR の行は独立した比較ではない)。
