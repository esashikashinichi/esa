# 解析43: 1万円→3万円まで最短の組み合わせ

> 共通の前提: GOLDmicro、0.01 ロット基準(1ドル ≒ 1.576円)、スプレッド約 0.55 ドル(価格×0.000128)、スプレッド2倍は悪化の確認。シグナルは足の確定で判定し次の足の始値で発注。足の中は逆行を先に処理。データ: M15 2024-07-23〜2026-09-21(2.16年)、M5 2026-04-13〜09-21(約5か月)。M1 は参考のみ(信用しない、Shinさん指示)。
> 注意: 多数の組み合わせから選んだ結果で、見かけが良く出ている。窓開け・スワップ・XM の実スプレッド(不明)は未反映。

## 方式
開始時期を毎月ずらした20通りで、3倍(3万円)到達までの日数の中央値を出す。
## 結果
- R 基準 K=1000: 中央値 212日、20/20 到達、落ち込み最大 36%、M5 +43%、取引順入れ替え(ブートストラップ)の落ち込み95%点 49%。
- R ×1.5 利確0.3 K=1000: 172日(落ち込み最大 56%)。
- 名目最短: R + recross RSI14 ×1.5 利確0.3 K=750 → 104日。ただし落ち込み最大 91%、M5 −27% で不採用。
- 開始ロット 0.10 では最悪の1回の損が −2,580円(資金の 26%)。
