# 解析46: ナンピンを増やす・インジケーター2〜3個の組み合わせ

> 共通の前提: GOLDmicro、0.01 ロット基準(1ドル ≒ 1.576円)、スプレッド約 0.55 ドル(価格×0.000128)、スプレッド2倍は悪化の確認。シグナルは足の確定で判定し次の足の始値で発注。足の中は逆行を先に処理。データ: M15 2024-07-23〜2026-09-21(2.16年)、M5 2026-04-13〜09-21(約5か月)。M1 は参考のみ(信用しない、Shinさん指示)。
> 注意: 多数の組み合わせから選んだ結果で、見かけが良く出ている。窓開け・スワップ・XM の実スプレッド(不明)は未反映。

## 結果
- ナンピン段数 2→8 で勝率 98.1→98.9% だが PF は下がり、落ち込みは約1.8倍。8段 ×1.5 損切15 の損切り時の損失は約 −5,972円(資金の 60%)と推定。
- 範囲を絞った最良: Supertrend(10,3)+H4 ナンピン2段(幅0.5・×1.5・損切15)+ピラ2・利確0.3: M15 勝率 98.7%・PF 3.82・+8,018円・落ち込み −1,389円、M5 PF 1.60。複利 K=3000: M15 100,922円(落ち込み 37%、スプレッド2倍 66%)、K=2000: 177,724円(落ち込み 31%、ただし M5 で 64%)。
- 3個の組み合わせ(トリガー+確認2つ)の PF 中央値 1.54(2個は 0.96)。最良 DI+UT(1,10)+H4ADX ナンピン2+ピラ2: M15 PF 1.60・M5 PF 1.76、ただし複利は弱い(K=2000 で 17,583円)。
