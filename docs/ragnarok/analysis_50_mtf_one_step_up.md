# 解析50: MTF(1つ上の足)フィルター

> 共通の前提: GOLDmicro、0.01 ロット基準(1ドル ≒ 1.576円)、スプレッド約 0.55 ドル(価格×0.000128)、スプレッド2倍は悪化の確認。シグナルは足の確定で判定し次の足の始値で発注。足の中は逆行を先に処理。データ: M15 2024-07-23〜2026-09-21(2.16年)、M5 2026-04-13〜09-21(約5か月)。M1 は参考のみ(信用しない、Shinさん指示)。
> 注意: 多数の組み合わせから選んだ結果で、見かけが良く出ている。窓開け・スワップ・XM の実スプレッド(不明)は未反映。

## 方式
上位足は M1→M5、M5→M15、M15→H1(確定足のみ)。フィルター: mEMA(上位足終値>EMA50)/ mST(上位足 Supertrend)/ mDI(+DI>-DI かつ ADX>20)/ mEMA+mDI。
## 結果
- MTF で PF 中央値が上がる(M15 買い・買い増し無し 0.94→1.07、M5 0.88→1.03)。M1 では効かない(PF 中央値 0.69〜0.74、ほぼ全て赤字)。
- 3つの足の全てで頑健だった形(7/620): DI クロス mEMA+mDI ナンピン2+ピラ2 利確0.3(M15 PF 1.95・+1,832円・落ち込み −665円、M5 PF 1.17、M1 PF 1.22)ほか。
- H1 は H4+ADX を超えない(DI mEMA ナンピン2: PF 1.88 対 2.39)。
