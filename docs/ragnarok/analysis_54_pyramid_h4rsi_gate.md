# 解析54: H4 RSI が少し下がるまでピラミッディング

> 共通の前提: GOLDmicro、0.01 ロット基準(1ドル ≒ 1.576円)、スプレッド約 0.55 ドル(価格×0.000128)、スプレッド2倍は悪化の確認。シグナルは足の確定で判定し次の足の始値で発注。足の中は逆行を先に処理。データ: M15 2024-07-23〜2026-09-21(2.16年)、M5 2026-04-13〜09-21(約5か月)。M1 は参考のみ(信用しない、Shinさん指示)。
> 注意: 多数の組み合わせから選んだ結果で、見かけが良く出ている。窓開け・スワップ・XM の実スプレッド(不明)は未反映。

## 方式
入口後の H4 RSI(14)(確定足、売りは 100−RSI)の最高値から X ポイント下がったら、以降の順行の買い増しを止める。X=1/2/3/5/8、最大段数 4/6、幅 1.0/0.7 ATR。複利 K=1500。
## 結果(最大段数4・幅1.0)
| X | PF | 損益(円) | M15 複利 通常/スプ2倍(円) | M5 通常/スプ2倍(円) |
|---|---|---|---|---|
| 基準(2段・ゲート無し) | 2.0 | 5,331 | 124,377/54,584 | 12,880/9,350 |
| 1(=2) | 1.8 | 3,885 | 81,833/54,627 | 10,929/11,004 |
| 3 | 1.8 | 3,958 | 84,161/37,158 | 10,929/8,073 |
| 5 | 1.8 | 4,341 | 95,042/38,300 | 11,357/8,435 |
| 8 | 2.0 | 5,584 | 132,264/67,287 | 11,383/8,487 |
- H4 RSI は4時間ごとにしか変わらないので X=1 と 2 は同じ。幅0.7 の組は落ち込み約50〜61% のまま。
## 結論
効果なし。ピラミッディングは R の 2段・幅1.0 のまま。
