# 解析55: 上位5候補を1つの EA で同時に動かす

> 共通の前提: GOLDmicro、0.01 ロット基準(1ドル ≒ 1.576円)、スプレッド約 0.55 ドル(価格×0.000128)、スプレッド2倍は悪化の確認。シグナルは足の確定で判定し次の足の始値で発注。足の中は逆行を先に処理。データ: M15 2024-07-23〜2026-09-21(2.16年)、M5 2026-04-13〜09-21(約5か月)。M1 は参考のみ(信用しない、Shinさん指示)。
> 注意: 多数の組み合わせから選んだ結果で、見かけが良く出ている。窓開け・スワップ・XM の実スプレッド(不明)は未反映。

## 方式
各候補を別マジックで同時に動かし、バーごとの損益を足して共通の複利倍率 m=floor((1万円+確定損益)/Kc)(最小1・最大30)を掛ける近似。Kc=5000 で各候補 0.02 ロット(合計 0.10 ロット = R 1個の K=1000 と同じ)。R 1個では正確なエンジンの結果とほぼ一致(誤差 1% 以内)。
- A 速さ上位5(解析51の1〜5位。入口は全て R が土台で重なる)。B M5 で頑健な5(R または MACD押し(利確0.5)/ DI×MMT zone / DI×MMT flip / Ichimoku TK+雲×MMT flip / DI+H4 ナンピン2)。
## 結果(Kc=5000、M15 通常/スプ2倍、M5 通常/スプ2倍)
| セット | M15 最終(円) | 落ち込み | 3倍まで(日) | M5(円)/落ち込み |
|---|---|---|---|---|
| A | 493,547 / 180,022 | 25/40% | 264/551 | 11,346 / 8,763、24/24% |
| B | 329,611 / 266,295 | 34/34% | 551/552 | 14,054 / 15,294、32/29% |
| R 1個(K=1000) | 151,360 / 76,206 | 32/54% | 259/556 | 14,338 / 8,477、30/46% |
- Kc=2500(合計 0.20 ロット)は A・B とも落ち込み 50% 超。Kc=7500(0.07)なら A M15 20/24%、B M15 20/19%、M5 12/13%。
## 結論
A は R を5分割しただけでスプレッド2倍の M5 は弱いまま。B は型が分散していてスプレッド2倍でも崩れない。Kc は 5000〜7500 が上限。
