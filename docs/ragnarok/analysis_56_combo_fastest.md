# 解析56: 複数方式の組み合わせ(1つの EA で同時に動かす)で、1万円→3万円まで最短の組を探す

> 共通の前提: GOLDmicro、0.01 ロット基準(1ドル ≒ 1.576円)、スプレッド約 0.55 ドル(スプレッド2倍を悪化の確認)。M15 2024-07-23〜2026-09-21、M5 2026-04-13〜09-21。M1 は参考のみ。多数の組み合わせから選んだ結果で見かけが良く出ている。窓開け・スワップ・XM の実スプレッド(不明)は未反映。

## 方式
- 候補 20個(解析51の候補)から 1〜4個の全組み合わせ 6,195通り × 合計の複利の強さ Kc 12段階(500〜20000)。Kc は各方式が m=floor((1万円+確定損益)/Kc) 倍(最小1・最大30)で動く値。合計ロット = 方式数 × m × 0.01。
- 学習: M15 2024-08〜2026-04-12、始点6通り(2024-08/11、2025-02/05/08/11)。制約: 落ち込み最大が上限(通常/スプレッド2倍)以内。その中で最小の Kc を選び、3倍(3万円)までの日数の中央値で並べる。
- 検証(選ぶ時に見ていない期間): 2026-04-13〜09-21 を M5 足の約定で、同じ Kc で実行。
- 近似: 各方式を 1 単位で走らせたバーごとの損益を足し、共通の複利倍率を掛ける(R 1個で正確なエンジンとの誤差 1% 以内)。

## 結果
| 学習の落ち込み上限 通常/スプ2倍 | 学習で最短 | 上位20個の M5 検証通過 | 検証に通った中の最短 |
|---|---|---|---|
| 45/55% | 67日(Kc=1500) | 0/20(M5 の落ち込み 66〜91%) | 139日(Kc=2000) |
| 35/45% | 95日 | 0/20 | 152日(Kc=3000) |
| 30/40% | 113日 | 0/20 | 152日 |
| 25/35% | 153日(Kc=3000) | 5/20 | 158日 |
- 通過の定義: M5 通常 11,000円以上かつスプレッド2倍 10,000円以上、落ち込みがそれぞれ 45%・55% 以内。
- 単体の学習(同じ期間・始点6通り): R または recross RSI2 ×1.5 が 150日(M5 で崩れる)、R または MACD押し(利確0.3)が 213日。
- 学習で最短の組(67〜113日)は、R または recross RSI2・RSI14(入口が重なる2個)と Supertrend 幅0.5 を含む組が中心で、M5 では 1万円割れか落ち込み 53〜76%。

## 通過した主な組(Kc、開始合計ロット、学習の3倍到達、学習の落ち込み 通常/スプ2倍、M5 残高 通常/スプ2倍(円)、M5 落ち込み)
1. R または recross RSI2 ×1.5(利確0.3) / Supertrend(10,3)+H4 ナンピン2(幅1.0・×1.5・損切15)+ピラ2(利確0.5) / DI×MMT Fixed%zone×VixFix(H4+ADX)ナンピン2 / Donchian55+H1H4 ピラ2: Kc=2000(0.20)、139日、35/46%、14,592/15,550、43/54%。
2. Supertrend 幅1.0 ナンピン2+ピラ2 / DI×MMT Fixed%flip×VixFix ナンピン2 / Donchian55+H1H4 ピラ2 / Nadaraya-Watson(H1 DI)ナンピン2+ピラ2: Kc=2000(0.20)、148日、34/47%、11,783/13,619、43/45%。
3. R または MACD押し(利確0.5) / R または recross RSI14 ×1.5(利確0.3) / Supertrend 幅1.0 ナンピン2+ピラ2 / DI×MMT zone×VixFix ナンピン2: Kc=3000(0.12)、158日、24/34%、12,766/10,915、38/54%。
4. R + ピラ ×1.5(利確0.3) / R または recross RSI14 / Supertrend 幅1.0 / DI×MMT zone×VixFix: Kc=3000(0.12)、158日、24/31%、11,168/10,757、36/53%。

## 結論
- 組み合わせは単体より速くなる(139〜158日、単体で M5 に耐える R または MACD押しは約213日)。
- 学習の最短だけで選ぶと未使用期間で崩れる(上位20個は 0/20〜5/20 しか通らない)。落ち込みの上限を絞る(25/35%)と通過率が上がる。
- 学習の落ち込み 24〜35% が M5 で 38〜54% に膨らむ → 学習の落ち込みは過小評価。合計ロットは学習で許容する値の約半分が目安。
- 通過した組は入口の型が全て違う(RSI の押し目・MACD・Supertrend・DI・Donchian)。入口が重なる2個を入れると崩れる。
- 通過した組は選ぶ段階で M5 を見ているので、この検証はもう完全な未使用ではない。
