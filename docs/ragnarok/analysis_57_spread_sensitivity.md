# 解析57: XM ゴールドのスプレッドの記事と、スプレッドの感度

> 共通の前提: GOLDmicro、0.01 ロット基準(1ドル ≒ 1.576円)、複利、1万円スタート、M15 2.2年・M5 2026-04〜09。多数の組み合わせから選んだ結果で見かけが良く出ている。

## 記事(Shinさんが貼付、海外FXふぁんくらぶ「XMのゴールド・金のスプレッド」、更新日 2026-08-27 と表記)
- スタンダード/マイクロ: 10時〜 4.2、15時〜・18時〜・21時〜 3.8〜4.0(pip)。KIWAMI極 1.8〜2.8、ゼロ口座 1.8〜2.2。
- 例の計算(価格 2,000 ドル、1ロット 40 ドル = 4.0 pip)から 1 pip = 0.1 ドルと読むと、スタンダード/マイクロは約 0.38〜0.42 ドル(これは推定)。
- スプレッドが広がるのは、日本時間 7〜9 時、指標発表直後、0分・30分をまたぐ時。
- 記事の信頼度: 価格 2,000 ドル時の計算で、現在の価格(約 3,600〜4,400 ドル)の実測ではない。アフィリエイト記事で公式値ではない。GOLDmicro が同じとは断定されていない。

## 想定との比較
- バックテストのスプレッド = 価格×0.000128 = 平均 0.47 ドル(2.2年平均価格 約 3,640)、M5 期間 0.56 ドル(価格 約 4,375)。スプレッド2倍 約 0.9〜1.1 ドル。

## 結論
- 記事の値(0.40 ドル)なら、R または MACD押し は想定(0.55)より M15 約 +14%、M5 約 +13%。
- R + ピラミッディング2段はスプレッドに最も弱い(0.80 ドルで M5 が 1万円割れ、M15 の落ち込み 54%)。R または MACD押し は 1.10 ドルでも M5 で 1万円を保つ。
- 実測が確実: EA_Monitor v3.9 に毎分の Ask−Bid 記録を足す案(作る前に確認、ルール1)。実測が出るまでは 0.55 ドルを基準、約 1 ドルを悪化想定に。
- 新規停止の候補: 日本時間 7〜9 時、指標直後、0分・30分またぎ(バックテストはスプレッド一定で、時間帯別は未反映)。
